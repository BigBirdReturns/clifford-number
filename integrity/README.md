# Evidence Desk: contracts, capital and retained source records

This is an owner-local review projection of existing Clifford Number research, with a portable browser desk and explicit executable/artifact edges to Cantos / Second Run and MARY. It does not change canonical evidence, the public publication allowlist, or the current website. No scoring, partner enrollment, paid inference, resource purchase or background service is introduced.

## Immediate entry

Open the assembled `index.html`, or double-click `OPEN EVIDENCE DESK.cmd`. Search works without an account, network, server or Python. Source inspection retains dates, native statuses, separate financial quantities and qualifications. JSONL and CSV downloads use embedded copies of the exact compiled export bytes, including in `file://` mode.

The owner runtime also provides:

```
python -B run.py verify
python -B run.py inspect --state /operator/owned/state
python -B run.py ask --query Firestorm --state /operator/owned/state
```

`inspect` calls Cantos's native shared-work runner with the new `evidence-inspect` adapter. A second invocation checks and reuses the retained computation. `ask` calls MARY's native `MachineProcess` against a single pinned read-only Clifford executable and records an occurrence in MARY's existing outcome ledger. Retrieval has no human review or publication effect. These deterministic paths need Python 3.10+ and no third-party Python packages. They do not invoke a language model or the household mirror.

## Build

From this checkout, supply the explicitly admitted component source directories:

```
python -B integrity/assemble.py \
  --repo . \
  --source-ref <published-source-commit> \
  --cantos /path/to/cantos-checkout \
  --mary /path/to/mary-checkout \
  --out /new/owner-local/edition
```

Cantos must include `integration/task_evidence.py` and its `work.py` registration. MARY must include `mary/evidence.py`. Assembly copies only the declared executable/package boundary into the output and records source coordinates and SHA-256 hashes in `COMPONENTS.json`. Source paths are build inputs, not runtime imports into sibling checkouts. Selected component code must be committed; assembly rejects dirty selected code. `--source-ref` pins the public data revision separately from local integration commits. The compiler calls Clifford's existing Genesis-reconciled `tools/lib/axm-id.mjs` through a fixed Node executable bridge. Node and Git are rebuild dependencies only.

Each source file must match its pinned Git revision. A dirty or changed source fails rather than publishing a URL for different bytes. Build time is distinct from the retained observation date. Existing editions are never overwritten.

## Frozen source selection for the first edition

The neutral selection unit is every retained row in the seven named source collections, not a selection of favorable or adverse claims. The first edition contains 124 rows:

- 17 government-award observations from the existing defense-router ledger.
- 17 BVVC financing/investment observations and all 30 current-snapshot portfolio labels.
- All 20 companies in the retained SCHOOLHOUSE 2024 Demo Day roster and all 18 retained faculty labels.
- 21 Anduril case claims with public supporting locators; three claims with private or unresolved locator support are explicitly excluded.
- The existing X-Bow award-source reconciliation.

The first edition is a deliberately curated demonstration of existing research. It is not a market census, an up-to-date November 2026 source refresh, or coverage of the entire repository. Schoolhouse legal-identity research, NHS/Palantir, the wider NatSec100 corpus, bulk FEC/OGE/ICIJ material and other retained lanes remain outside this projection. Exclusion does not imply irrelevant, absent, false or cleared material.

Source grades remain mixed. Native `verified` in a source ledger is preserved separately from the desk's `requires_independent_review`. Listing does not establish ownership. A contract ceiling is not an obligation or a payment. Unknown payment is not zero. The Saronic initial order is not total government footprint. Cambium's held recipient identity stays held. No source-specific numbers are summed across overlapping ledgers.

## Integrity.ai boundary

`exports/review-inbox.jsonl` is an integration candidate for human review. It carries source URLs, source-record pointers, native evidence/status, date, identity state, exact decimal financial values and limitations. Consumer `dimension`, `polarity`, `weight` and `registry_status` are null. No accepted consumer schema, endpoint import, score impact, partnership or endorsement is claimed. A source-record reference is not automatically an Integrity Registry corporate entity.

The documented external methodology used to scope this candidate is the abridged registry/pipeline publication, not a tested production API: `https://braxtonjarratt.com/integrity-engine/registry-methodology.html` and `https://braxtonjarratt.com/integrity-engine/registry-pipeline.html`.

## Verification

```
python -B integrity/qualify.py --bundle /edition --out /new/software-checks
python -B integrity/browser_check.py --bundle /edition --out /new/browser-checks
```

The first command exercises real source counts, historical scope, private-support exclusion, held identities, unknown payments, source disagreement, malformed queries, file corruption, incomplete excerpts, forbidden review promotion, native cold execution/reuse, changed-task execution, partial failures, corrupt-cache holds, actual MARY retrieval and refusal of write/path-injection requests. The second needs Playwright and an installed Chrome binary and tests the actual offline browser, exact export downloads, desktop/narrow layout, bookmarks and lack of network requests. Test copies are explicitly mutated artifacts; the research sources remain unchanged.

A byte inventory is intentionally unsigned. It verifies consistency with supplied hashes, not publisher identity or source truth. An independent human claim review remains separate from automated software tests or model code review.
