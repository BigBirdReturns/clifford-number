# PC-50 executable artifact, build, dependency, environment, and runtime identity custody

PC-50 is a synthetic Preference Custody control. It holds one public source, build, artifact, dependency, runtime, execution-attestation, replay, and interval surface constant across eight incompatible provenance worlds.

Only the positive world binds the reviewed repository and exact source tree to a reproducible build; the build to signed artifact, package, executable, entry point, container manifest, layers, and base image; the artifact to the complete resolved dependency graph and supply-chain receipts; the image to the operating system, kernel, runtime, libraries, environment, mounts, and network policy; and the running process to loaded modules, service snapshots, invocation, output, correction, and current lineage.

The seven refusal worlds preserve the same public badges while separating source-review substitution, build and toolchain divergence, artifact or entry-point substitution, dependency and supply-chain drift, container and runtime drift, loaded-module or invocation drift, and inherited stale assurance.

The control does not establish that a real artifact was compromised, that a real build is reproducible, that a real dependency graph is safe, that any real runtime executed reviewed bytes, or that any named person or institution acted improperly. It produces no graph, publication, adoption, causal, prevalence, security-compromise, coordination, common-purpose, intent, or public-authority finding.

## Promotion boundary

A real executable-identity claim still requires current, hash-linked custody for the reviewed source, complete build inputs and toolchain, independent reproduction, artifact and package identities, signatures and provenance, complete dependency graph and checksums, container and base-image layers, operating environment, runtime and loaded modules, invocation and service snapshots, source-to-output attestations, negative controls, succession, monitoring, correction, rollback, retirement, durability, and separate public authority.
