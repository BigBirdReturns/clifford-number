# Story Ecology and Answerable Power

## Purpose

The project can explain **Matt Clifford**, **Palantir**, and **Anduril** as separate institutional histories and as exact overlap stories without turning shared fields, people, customers, vocabulary, or chronology into one unproved organism.

The unit of work is not a logo. It is a bounded story with an evidentiary ceiling.

```text
standalone story
+ exact overlap story
+ constitutional mechanism
+ counterpower answer
+ explicit non-link
= sustainable explanatory ecology
```

## Five story modes

### 1. Standalone actor

Reconstruct the actor's own formation, institutions, rights, resources, public gates, operating roles, failures, affected people, counterpower, and exit history.

A standalone story must not borrow causation from another actor merely because they occupy the same ecology.

### 2. Exact overlap

An overlap exists only through a dated, identifiable bridge:

```text
exact parties
→ exact instrument
→ date window
→ role or rights
→ operating consequence
```

Co-presence, ideological compatibility, shared investors, shared customers, or similar products remain acquisition signals.

### 3. Constitutional mechanism

Explain the distribution of:

```text
purpose
categories
thresholds
evidence
action rights
exceptions
burdens
benefit
remedy
```

This is how separate actors can participate in the same system while retaining different objectives and powers.

### 4. Answer story

An answer is not a recommendation. It is an intervention with an observed result.

```text
problem
→ authority to intervene
→ timing
→ implementation
→ outcome
→ durability
→ transfer limit
```

### 5. Non-link

The ecology preserves failed joins as first-class results. A map that hides its broken bridges becomes advocacy rather than cartography.

## The answerable-power ladder

```text
R0 representation without authority
R1 timely notice and voice
R2 inspection and correction
R3 pause and burden shift
R4 reversal and effective remedy
R5 substitution and public capacity
R6 co-governance over purpose, category, and termination
R7 value recovery
```

Formal safeguards do not automatically move a system up the ladder.

```text
appeal without a stay
≠ preventive power

human review
≠ meaningful veto

customer data ownership
≠ practical custody

termination clause
≠ completed exit

criticism
≠ counterpower
```

## What “works” means

The project is not complete when it has mapped every actor. It is complete only when it can show a repeatable answer to power asymmetry.

The minimum cross-domain standard requires observed interventions in at least three domains and two jurisdictions, covering:

- pre-action timing;
- evidence access;
- independent authority;
- effective remedy;
- durability;
- practical exit or co-governance.

A policy on paper is not enough. A one-time reversal is not enough if the same function reappears under a successor system. Vendor replacement is not enough if public operating capacity does not exist.

## Sustainability

Every public explanation must be reproducible from canonical inputs.

Each story carries:

```text
source routes
claim disposition
maximum ceiling
counterevidence
non-links
falsifier
stopping rule
version history
```

A source change triggers reconciliation. A retired account remains versioned. No generated story may promote a claim beyond its source record.

## Boundary

```text
standalone similarity proves overlap: false
overlap proves common purpose: false
formal safeguard proves effective power: false
criticism proves counterpower: false
vendor exit proves public capacity: false
story coherence proves truth: false

promotes_to: candidate_only
graph_effect: none
conclusion_generated: false
estate_completion_claimed: false
```
