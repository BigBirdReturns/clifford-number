# Counter-Selector blind-review method

Wave 04 reviews the two identity-minimized packets produced by Wave 03. The review surface contains the task, requirements, bounded chronology, observable transition, counterevidence, and falsifier. It does not contain candidate identity, title, employer, jurisdiction, denominator class, source route, matched control, or status metadata.

Each packet receives two fresh-context passes. The artifact-validity pass asks whether the object is bounded, internally reviewable, and capable of supporting any narrow dimension claim. The adversarial-countermodel pass tries to explain the same residue through ordinary support, institutional authority, later reconstruction, incomplete merits, or a mistaken unit of analysis. The passes are procedurally separated but run inside the same system. This wave therefore claims no external-human, different-model, or different-institution independence.

The synthesis does not average scores. It preserves disagreements and resolves them by narrowing authority. `bounded_support` is not an operator finding. A statutory or institutional correction route is not automatically evidence that a partnership repaired itself. Missing support, custody, transfer, or final-merits receipts remain acquisition requirements rather than negative capability evidence.

The private packet-to-candidate map is restored only after the blind passes for custody and append-preserving class review. A class change is a recommendation, not a rewrite of historical intake. No review result authorizes contact, field testing, identity release, promotion, ranking, or graph effects.
