# Counter-Selector external-gate execution

Wave 22 distinguishes **contact execution** from **evidence acquisition**.

A Gmail `SENT` receipt proves only that the authenticated mailbox submitted a message. It does not prove recipient delivery, reading, archival custody, record existence, or evidentiary support. Automatic replies are classified by what they actually establish: service availability, not the existence or absence of requested records.

Every response remains append-only. A locator, scan, acknowledgment, refusal, bounce, or independent review becomes a new object with its own source state and authority ceiling. Silence never becomes negative evidence, and repeated follow-up is not authorized merely because a request was sent.
