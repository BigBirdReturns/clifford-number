# Counter-Selector support-adjusted surplus audit

Wave 25 attacks the final unresolved operator dimension with matched controls instead of treating high-status success as self-normalizing.

The audit separates four comparison surfaces:

```text
same-event role-adjacent conduct
joint mission contribution
successor-role continuity under changed policy
policy revision without a matched peer
```

A comparator is valid only when mandate, authority, staff, access, infrastructure, timing, external conditions, and outcome measure are sufficiently aligned to estimate residual output. Similar titles, the same historical event, shared mission success, or a successor occupying the same broad role are not enough.

The output is categorical. It creates no score, rank, promotion, field-test authority, public identity profile, or graph effect.
