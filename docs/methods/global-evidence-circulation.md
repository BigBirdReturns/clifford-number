# Global Evidence Circulation

M-04G Wave 02 turns the inland sea into a repeated jurisdiction-preserving circulation system.

```text
12 basins
+ 8 cross-border currents
+ 192 source routes
+ 96 bounded public polls
→ repeated orbital artifacts
→ estuary candidates
→ human adjudication
```

The method proves circulation by requiring an independently executed artifact for every expected basin and a consolidated orbit proof. It does not treat geographic scale, translation, shared vendors, shared terminology, or source volume as evidence of completeness, transfer, coordination, or common governance.

## Basin law

Each basin receives exactly:

```text
2 ocean-discovery routes
8 authoritative freshwater routes
3 deployment-specific voice routes
3 archival or lawful aquifer routes
8 public pilot polls
```

Direct voice is never bulk-polled. Translation is not performed silently. Restricted access is never bypassed. Network observations are artifact-only candidates and cannot change canonical findings.

## Cross-border law

A transfer requires a sending record, exact transferred object, date and mechanism, receiving record, local implementation, and counterevidence. Similarity is not transfer.

## Proof outputs

Each basin writes observations, failures, changes, candidates, state, and an orbit manifest. The proof job reconciles the expected basin denominator and emits a checksum-bound global orbit proof.
