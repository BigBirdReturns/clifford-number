# Allocator-war denominator closure fan-out Wave 25 method

Wave 25 converts every explicit `unavailable_rows` obligation retained by the eleven Wave 24 packet plans into a deterministic estate-owned closure task. The source unit remains the Wave 24 packet. The task unit is one unavailable obligation in source order. The compiler does not infer additional missing records, merge similar obligations across estates, or promote any acquisition row into evidence.

Each estate receives one JSONL closure queue. The first row is a queue summary preserving the packet, estate, authority class, bounded window, source acquisition disposition, institutional-gate state, source references, coverage statement, unavailable rows, refused substitutions, and negative-search statement. Each following row is one closure task with a stable reference, deterministic class, priority, execution state, required output, closure test, allowed terminal states, inherited controls, and blocked promotions.

Task classification is rule-based. A missing institutional decision surface becomes `gate_identification`. A missing candidate, applicant, bidder, affected-person, regulated-entity, programme, roster, or option universe becomes `denominator_closure`. Missing agreements, schedules, criteria, evaluation records, FOCI custody, contracts, rights, interfaces, rules, or guidance become `instrument_rights_recovery`. Exact cross-system legal-entity work becomes `entity_resolution`. Remaining performance, implementation, appeal, remedy, substitution, exit, recovery, and consequence obligations become `outcome_correction_recovery`.

Priority orders acquisition work rather than truth or importance. Gate identification is `G0`, denominator closure is `P0`, instrument and entity work is `P1`, and longitudinal consequence or correction work is `P2`. Source order remains the tie-breaker inside each packet.

The two Wave 24 packets that ended with `bounded_public_record_recovered_gate_unspecified` are gate-first queues. Each contains exactly one ready gate-identification task. Every downstream denominator or consequence task in the same queue remains `blocked_pending_gate_identification` until the gate task terminates as complete, partial, contradicted, no qualifying gate, unavailable after search, or outside the bounded window. A negative gate result remains a terminal record and does not authorize an invented selector or decision surface.

The nine packets with named institutional surfaces are immediately ready for targeted acquisition. Their tasks still retain incomplete-denominator status. Queue admission does not execute the search, prove source availability, adjudicate evidence, establish prevalence, create a relationship, or clear publication.

The builder removes and regenerates the Wave 25 queue directory, preserves packet and unavailable-row order, hashes each complete queue, records exact source-plan and source-projection byte hashes, and emits one deterministic projection and report. Adversarial tests mutate task classification, priority, gate blocking, source custody, queue hashes, evidence state, graph boundaries, and lake authorization to prove that each failure is detected.
