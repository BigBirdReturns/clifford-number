# No-magic-human gate

The project must never depend on a hypothetical outside person arriving to supply judgment, permission, review, legitimacy, or rescue.

External participation is a **claim-specific evidence state**, not a global project gate. A missing external reviewer means only that the exact claim `externally reviewed` remains false. It does not stop source acquisition, internal adversarial review, bounded judgment, falsification, publication with honest authority labels, stable-ground succession, testing, release, or hypothesis revision.

```text
no external receipt
→ record zero
→ preserve the authority ceiling
→ continue every non-dependent lane
```

The inverse is forbidden:

```text
no external receipt
→ ask the user to recruit strangers
→ wait for a reply
→ suspend unrelated work
```

## Outreach boundary

The default outreach state is **off**. The project may not create drafts, send messages, invite reviewers, or ask the user to find people unless the user explicitly requests that outreach in the current conversation. Candidate discovery, a public email address, an open review issue, or a zero-review denominator is not authorization.

## What an outside receipt can change

An authenticated, conflict-evaluable, packet-bound external review can support only the claim that the packet received that external review. It does not automatically adjudicate disagreement, rewrite the canonical disposition, clear publication, create a graph edge, establish prevalence or intent, or advance adoption.

The same rule applies to adjudication and adoption. Their absence is recorded as zero; their presence changes only the authority supported by the exact receipt.
