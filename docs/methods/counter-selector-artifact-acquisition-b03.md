# Counter-Selector Batch 03 acquisition

Batch 03 preserves one object from each denominator class. A record qualifies only when official custody supplies a bounded work, warning, or failure sequence with provenance, a decision surface or observed use, counterevidence, and a falsifier. Later investigations may carry embedded contemporaneous objects, but they do not create individual authorship or operator findings.

Partial acquisitions remain in the denominator. Accident consequence is not operator capacity, a congressional staff report is not independent merits, policy architecture is not observed repair, and external correction is not a repair-capable partnership.
