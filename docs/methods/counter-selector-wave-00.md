# Counter-Selector Wave 00 method

Wave 00 hardens the installed `counter-selector-v1` programme before any candidate denominator is populated.

The protocol uses blind-first artifact review, then restores support, authority, state load, identity, and context before disposition. It never treats poverty, rejection, outsider identity, AI use, breadth, confidence, or similarity to the founder as capability evidence.

## Sequence

```text
artifact intake
→ blind-first review
→ support ledger
→ transfer test
→ disruption test
→ custody and handoff
→ second-party review
→ consented bounded collaboration
```

The evidence vector remains dimensional. No aggregate score or universal rank is generated.

## Governing rule

> Evaluate the artifact and state transition before evaluating the biography. Evaluator incomprehension creates an acquisition requirement, not a negative capability finding.

## Anti-oracle rule

AI may assist retrieval, comparison, branch preservation, drafting, and validation. AI-generated accounts of motives, destiny, superiority, persecution, or hidden coordination never substitute for chronology, artifacts, sources, observed behavior, or a recoverable intervention.

## Candidate sovereignty

Identity is withheld by default. Public traces do not authorize identity release. Collaboration requires consent, bounded scope, reciprocal value or compensation, a stop rule, privacy terms, and a clean exit.

## Field threshold

Wave 01 may begin only after the schema, matched controls, false-positive controls, deterministic build, validator, adversarial mutations, and exact-byte release custody pass.
