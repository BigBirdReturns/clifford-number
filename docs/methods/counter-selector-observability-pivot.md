# Counter-Selector observability pivot

Wave 26 preserves the completed historical denominator and the seven-dimension Richardson control, but stops treating historical archival scarcity as the preferred candidate surface.

The pivot selects public-artifact lanes where the selector can inspect support, contradiction, exception handling, custody, succession, and resumability. It does not lower any gate, contact any source subject, or treat visibility as merit.

## Intake rules

```text
source route before biography
person/function split before attribution
public update trace before model-elasticity claim
observed handoff before custody promotion
support ledger before surplus
external review before promotion
consent before field test
```

Batch A contains the two person-attributable lanes with the broadest immediately inspectable update and governance surfaces. Batch B contains a collective custody system and a sensitive-data service that are especially useful for support and person/function controls.

The batch assignment is procedural. It is not a merit score or person rank.
