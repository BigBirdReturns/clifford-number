# Allocator-war lead acquisition execution Wave 24 method

Wave 24 executes the eleven Wave 23 lead packets as bounded acquisition records. It consumes the Wave 23 packet projection and the Wave 24 source plan, writes one packet-specific JSONL ledger for each estate, and emits a deterministic execution projection and report. The wave records what was recovered, excluded, unavailable, refused, and left without a bounded institutional gate. It does not adjudicate the acquired material as evidence.

Each ledger begins with one packet-execution row followed by one source-receipt row for every source reference assigned by the source plan. The packet row preserves the Wave 23 queue, task, consumer, authority class, acquisition target, required output, closure test, and source-authority references. It then records the bounded window, acquisition disposition, institutional-gate state, coverage statement, included and excluded rows, explicit nulls, unavailable rows, refused substitutions, negative-search statement, correction route, and observed correction outcome.

Source-receipt rows preserve the exact locator, resolved locator, stable identifier, issuing body, source type, jurisdiction, issue date, retrieval date, retrieval status, and inherited custody references. A stable official identifier may satisfy locator-level acquisition custody when source bytes are not preserved. It does not become source bytes, an executed instrument, a complete denominator, or an evidentiary conclusion.

Nine packets terminate at `partial_source_recovery`. Those packets identify one or more bounded institutional surfaces but retain incomplete candidate, applicant, bidder, affected-person, instrument, performance, or correction denominators. Two packets terminate at `bounded_public_record_recovered_gate_unspecified`. Those packets retain bounded research and demographic records while refusing to invent a legislative, finance, deservingness, or other institutional decision gate not supplied by the source chain.

The execution compiler treats acquisition disposition as a custody state rather than an evidence result. Every ledger therefore remains `acquisition_recorded_evidence_unadjudicated`, carries `complete_denominator: false`, creates zero evidence rows, and blocks estate, compact, racial-order, prevalence, coordination, common-purpose, identity, relationship, participation, active-claim, hop, and publication promotion.

The builder is deterministic. It orders packets by the Wave 23 packet sequence, preserves source order from the source plan, removes and rebuilds the Wave 24 ledger directory, hashes each complete JSONL ledger, and records source-plan and source-projection byte hashes in the execution projection. Adversarial tests mutate source identity, retrieval status, packet disposition, gate state, ledger custody, denominator state, evidence state, graph boundaries, and lake authorization to prove that each mutation fails closed.

Wave 24 remains graph inert. Shared sources across estates are repeated source uses, not relationships. Repeated selected surfaces are not prevalence. A blocked or failed retrieval is retained as an unavailable acquisition condition and is never silently converted into a null.
