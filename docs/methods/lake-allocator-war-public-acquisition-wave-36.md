# Allocator-war official-record public acquisition execution Wave 36

Wave 36 consumes the permanent Wave 35 task denominator and executes only the twenty-eight tasks admitted to public, separately authorized, or lawful-case acquisition. The three protected-personnel tasks remain in lawful-access-only custody and perform no network request. Public workforce aggregates, award records, litigation pages, and enforcement announcements cannot be used to manufacture protected personnel decisions, comparators, reasons, appeals, or outcomes.

The source cohort contains fifty bounded official requests. It combines the existing executive-instrument, implementation-guidance, public-money, enforcement, docket, adjudication, and correction records already routed in Waves 24 and 29 with current Acquisition.gov, Justice Department, GAO, and USAspending records. Requests are executed through a six-worker pool. Every request descriptor, request body, response status, final URL, selected response headers, response bytes, and response digest is preserved. A required source must return a usable response and pass its declared source-marker audit. Optional source failures remain visible as acquisition outcomes.

A usable response creates one source-backed institutional component row. The component carries the issuing body, date, stable source identifier, action class, response path, response digest, source-specific marker result, represented-value status where applicable, and every Wave 35 task to which it is routed. The represented-value field distinguishes announced awards, requested financing, settlement obligations, and fee-waiver estimates from realized payment or recovery.

Each Wave 35 task receives one result row. Its exact source map, capture states, response files, institutional component rows, completion gap, completion test, refused substitution, source join hash, and source requirement hash remain visible. Component recovery does not satisfy the task. Published actions cannot substitute for complete referral, investigation, declination, withdrawal, appeal, correction, or no-action registers. Docket presence cannot substitute for practical correction. Award names cannot resolve legal entities. Repeated actions cannot establish prevalence, coordination, or common purpose.

Wave 36 therefore moves the waterline from source-system addressability to frozen official record components. It still authorizes zero joins, complete denominators, evidence rows, estate adoptions, findings, graph effects, or publication clearances.
