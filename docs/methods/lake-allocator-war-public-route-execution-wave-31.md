# Allocator-war public-route execution Wave 31

Wave 31 executes the public portion of the Wave 30 missing-row frontier through reusable source-system lanes. The source denominator is exactly the seven Wave 30 routes and thirty-eight Wave 30 obligations. Thirty-four obligations are publicly executable. Four protected-personnel obligations remain preserved under a privacy-safe aggregate or otherwise lawful-access boundary.

## Execution model

The wave uses one official source set per route class rather than one search per obligation. A route-level source set is reused across every obligation assigned to that route, and a change to one source set requires replay only of that route. This preserves the Wave 30 amortization contract while creating an exact result for every source task.

The public source systems are grouped by function. OPM provides official federal-workforce aggregates and downloadable datasets. The Federal Register API provides published instruments and agency metadata. USAspending, SAM.gov, Grants.gov, and the Federal Audit Clearinghouse provide separate award, contract, assistance, and audit universes. DOJ publications provide bounded enforcement and settlement records. GAO, PACER, and MSPB provide bounded protest, judicial, and administrative correction surfaces.

## Result states

`partial_public_recovery` means an official system exposes a bounded part of the requested row set while the complete condition-specific denominator, no-action register, or final outcome universe remains open. `unavailable_after_public_search` means the declared internal record was not exposed by the bounded official public systems. `blocked_missing_join_denominator` means multiple official base systems exist but no complete lawful join identifies all affected, unaffected, comparator, burden, recurrence, and no-effect rows. `preserved_access_bounded` means public execution is not attempted because privacy-safe aggregate or otherwise lawful personnel access is required.

None of these states is evidence adjudication. Public system availability does not establish that the system is complete for the contested action. A base award or contract universe is not an action denominator. A published enforcement announcement is not a complete register unless the issuing system preserves all actions, declinations, and no-action rows. A docket or remand is not effective correction without final implementation, access, cost, and durability evidence. A missing public join is not a completed denominator.

## Deterministic custody

The builder verifies Wave 30 projection and ledger hashes, applies the seven route plans, writes one route summary and one result per Wave 30 task, counts every source use, and preserves the inherited graph digests. The validator rebuilds the entire Wave 31 object and requires exact equality across policy, source plan, projection, route ledgers, basin ownership, authoritative roots, installer registration, package scripts, and the repository release gate.

The adversarial suite mutates source custody, route ownership, task denominators, source sets, result states, source-use counts, evidence authority, graph authority, publication authority, basin membership, authoritative roots, installer registration, and release-gate registration. Every mutation must fail closed.
