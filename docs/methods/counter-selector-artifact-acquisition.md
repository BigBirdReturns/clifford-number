# Counter-Selector artifact acquisition

Wave 03 converts source routes into inspectable acquisition decisions without converting official status into operator merit.

## Admission law

A qualifying acquisition must preserve a bounded work object, decision record, correction sequence, or failure ledger; source-addressable custody; a bounded chronology; task requirements; an observable state transition; and explicit counterevidence and falsifier.

The following are insufficient by themselves:

- a later oversight summary;
- a settlement;
- a stay;
- a role label;
- a positive performance record;
- a public allegation; or
- an identity-minimized packet.

## Batch 01

Batch 01 keeps one object from each Wave 01 denominator class in the same acquisition train. Seventeen official locators were acquired. Two objects satisfy the bounded packet contract; four remain partial because the original warning, complaint, specialist work product, independent merits record, or final custody state is missing.

## Blind-packet law

Identity minimization removes names, institutions, titles, jurisdictions, source identifiers, denominator classes, and matched-control identity. It preserves task requirements, chronology, state transition, limits, counterevidence, and falsifier.

Packet construction is not blind review. No packet authorizes contact, field testing, public identity release, promotion, ranking, or graph mutation.

## Failure custody

Missing records remain named acquisition obligations. A partial is neither a negative capability finding nor a reason to drop the object from the denominator. Settlement and stay states remain distinct from final merits.
