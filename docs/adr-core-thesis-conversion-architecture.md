# ADR: Durable core thesis and conversion-architecture realignment

**Status:** accepted

## Context

Clifford Number’s bounded-surface compiler, evidence cases, estate registry, game trails, structured reports, and review waterlines make topology, custody, gaps, counterweights, and next acquisitions visible without allowing automation to generate findings.

The estate program also exposed a limit. Additional names and broad overlaps no longer answer the project’s hardest questions:

- where public strategy ends and private opportunity begins;
- who authored the available choices;
- whether competition remained meaningful before the option set narrowed;
- which instruments created durable public dependence or private control;
- who retained residual rights and value;
- and whether the public could inspect, contest, substitute, terminate, or reverse the system.

The project needs a durable thesis capable of organizing longitudinal research without converting that thesis into a finding.

## Decision

The project adopts `data/project/core-thesis.json` as its canonical, falsifiable research thesis and `data/project/estate-thesis-alignment.json` as the cross-estate routing contract.

The constitutional authority order remains:

```text
BUILD-INSTRUCTIONS.md
→ canonical evidence and identity registries
→ case and estate custody
→ core-thesis and estate-alignment research contracts
→ deterministic projections, visualizations, reports, and review queues
```

The core thesis cannot:

- create a bounded hop;
- add a claim, event, relation, or receipt;
- assign an intentionality level to an actor;
- create a graph edge;
- generate a finding or conclusion;
- change a report’s publication state;
- or declare an estate complete.

It may:

- define falsifiable project questions;
- organize overlapping historical phases;
- define conversion stages and recurring archetypes;
- prioritize decisive records and counterevidence;
- define data, visualization, and report contracts;
- and route independently reviewed evidence toward human synthesis.

## Historical model

The project uses five overlapping post-Cold War phases:

1. lean hegemon, 1991–2001;
2. expeditionary contractor state, 2001–2009;
3. innovation bridge, 2009–2016;
4. dual-use platform state, 2017–2021;
5. reindustrializing market-maker state, 2022–present.

Phase membership is contextual. It does not prove a causal sequence, common intent, or coordinated project.

## Conversion model

Cross-estate analysis uses seven stages:

```text
agenda formation
→ option-set formation
→ public conversion
→ control architecture
→ dependency and compulsion
→ residual value
→ reversibility and counterpower
```

A conversion chain is complete only when each transition is supported by typed, receipted, qualified evidence. Missing transitions remain open joins.

## Intentionality model

Actor-specific review uses six independent levels:

```text
structural convergence
→ opportunistic exploitation
→ deliberate market shaping
→ institutional replacement
→ coercive or ideological governance
→ personal extraction
```

The levels are neither a cumulative score nor a presumption that higher levels occurred. Each level has separate evidence requirements and falsifiers.

## Estate alignment

All twenty-four durable estates map to phases, conversion stages, archetypes, decisive record families, report types, and falsification questions.

Alignment does not merge estates or replace their denominators, source routes, nulls, controls, receipt custody, or review state. It allows the project to ask one longitudinal question through multiple domain corpora without creating a universal graph edge.

## Data consequences

Future case and estate work should add first-class objects for:

- problem frames;
- role claims;
- option-set snapshots;
- conversion events;
- control rights;
- dependency and compulsion states;
- residual-value positions;
- intent records;
- and reversibility or counterpower tests.

The existing claim, event, receipt, trail, and case structures remain authoritative. New analytical objects must resolve to those sources rather than duplicate factual prose.

## Visualization consequences

The project’s primary cross-estate visualizations become:

- a phase river;
- doctrine-to-deployment paths;
- option-set narrowing funnels;
- role-stacking matrices;
- control stacks;
- public-risk/private-rights flows;
- and compulsion/exit matrices.

The estate map and game-trail matrix remain routing instruments. They are no longer expected to carry chronology, option-set narrowing, rights allocation, compulsion, and reversibility simultaneously.

## Report consequences

The structured-report platform must be able to express:

- doctrine-to-deployment dossiers;
- strategic exploitation dossiers;
- institutional replacement reports;
- forced-compliance audits;
- public-risk/private-residual audits;
- ideological implementation dossiers;
- and comparative replacement and exit reports.

Every report continues to require canonical claims, explicit boundaries, counterweights, open records, and independent review.

## Project sequence

The new sequence is:

```text
preserve the bounded-hop and estate kernels
→ compile the core-thesis and alignment contracts
→ build conversion-chain and control-rights ledgers
→ migrate high-value existing cases into the conversion grammar
→ run actor-specific intentionality review
→ publish non-narrative conversion reports
→ seek independent synthesis and falsification
```

Priority goes to depth before new estate breadth.

## Rejected alternatives

- **Make the thesis the graph model:** rejected because a thesis cannot become an evidence relation.
- **Assign actors an influence or capture score:** rejected because evidence types and intentionality levels are not commensurable.
- **Treat post-2011 correlation as one coordinated plan:** rejected because actor-specific intent and implementation must be proved separately.
- **Use a single network graph as the wide view:** rejected because topology hides chronology, option-set exclusions, instruments, rights, risk, and exit.
- **Write one master narrative:** rejected because it would duplicate factual prose and obscure open joins, controls, and falsifiers.
- **Open more estates before realignment:** rejected because the existing twenty-four estates are not exhausted and already contain the decisive cross-domain seams.

## Boundary

```text
graph_effect: none
conclusion_generated: false
machine_synthesis_ceiling: eligible_for_human_synthesis
```

The core thesis is durable because it is explicit, versioned, falsifiable, and machine-validated—not because the project treats it as proven.
