# Epistemic diversity, source independence, and evidence-quality custody

PC-13 separates citation, speaker, expert, and agent counts from the independence, validity, visibility, and decision consequence of the evidence they carry. The control holds participant identities, final private preference, the ballot, the published majority, speaker count, and evidence-presentation count constant while changing the evidence-dependency graph and the exact proposal version adopted.

The fixture is synthetic. It creates no graph effect, thesis evidence, named-system evidence audit, truth verdict, consensus finding, collective-agreement conclusion, manipulation claim, legitimacy verdict, public-authorization finding, or inference of intent.

## Frozen state

```text
population                         1,000 retained participants
baseline private A preference      60%
post-process private A preference  80%
post-process A ballot              80%
published A disposition            80%
speakers presenting evidence         4
evidence presentations               4
```

The reference state distinguishes proposal family from proposal version:

```text
A0  efficient but fails the documented burden-safeguard constraint
A1  A0 plus the evidence-responsive safeguard; passes the constraint
B0  passes the constraint but has lower objective value than A1

reference-preferred proposal: A1
```

Every world ends with an 80 percent A-family majority. Only one adopts the reference-preferred A1 version.

## Six evidence systems behind one majority

### Independent diverse corroboration with minority correction

Four speakers present four independently rooted, valid, inspected, and visible evidence items: efficiency evidence supporting A, burden evidence challenging A0, safeguard evidence supporting A1, and comparator evidence supporting B0.

B_REVIEW challenges A0 with the burden evidence. A response presents the safeguard evidence. A0 is amended to A1. The minority challenge is taken up, B_REVIEW endorses the revised proposal, and the ballot adopts A1.

```text
root sources                    4
independence clusters           4
valid evidence items            4
visible evidence items          4
challenge                       1
response                        1
uptake events                   2
amendment                       1
final proposal                 A1
reference acceptable         true
```

This is the fixture’s one qualified source-diverse, evidence-valid, minority-responsive path.

### Derivative-source laundering

Four speakers cite four different documents. All four documents derive from one original efficiency source and occupy one independence cluster.

```text
nominal citations               4
speakers                         4
root sources                     1
independence clusters            1
derivative items                 4
final proposal                  A0
```

Deduplicating by root collapses the apparent corroboration to one source. Citation plurality is not evidentiary independence.

### Common-model expert monoculture

Four nominal experts or agents produce four outputs. Every output comes from the same model, corpus, and independence cluster.

```text
nominal agents                  4
model outputs                   4
root systems                    1
independence clusters           1
final proposal                 A0
```

Agent count does not establish model, corpus, retrieval, or benchmark diversity.

### Information cascade without source inspection

The first speaker inspects one primary efficiency source. Three later speakers repeat the claim through a derivation chain without inspecting the root or an independent source.

```text
presentations                   4
inspected evidence              1
uninspected repeats             3
root sources                    1
final proposal                 A0
```

Repetition increases social support for the claim without increasing independent evidence.

### Suppressed minority counterevidence

The evidence estate contains four valid and independent sources, including the burden audit and safeguard pilot. The burden and safeguard items are withheld from the decision surface. The visible set contains only two items, and the uncorrected A0 version is adopted.

```text
submitted valid sources         4
visible sources                 2
suppressed sources              2
submitted burden challenge      true
visible burden challenge        false
final proposal                 A0
```

Restoring visibility changes the adopted proposal from A0 to A1 while leaving the family-level 80/20 majority unchanged.

### Fabricated or poisoned evidence

Four independent-looking sources occupy four separate root and cluster identities. All four fail the fixture’s evidence-integrity state through fabrication or poisoning.

```text
root sources                    4
independence clusters           4
valid evidence                  0
integrity failures              4
final proposal                 A0
```

Source diversity is not evidence validity. Authentication and integrity remain separate controls.

## Evidence dependency is a graph object

A complete evidence ledger must preserve more than document titles:

```text
presentation identity
speaker identity and order
claim identity
source identity
root source identity
derivation parent
independence cluster
model, corpus, retrieval, and tool lineage
validity and integrity state
inspection and replication state
visibility and suppression state
proposal target
```

Four documents can be four independent roots, four derivatives of one root, four outputs of one model, or four independent fabrications. The count alone does not discriminate among them.

## Minority correction and proposal version

The qualified world does not treat minority status as a discount on evidence quality. B_REVIEW supplies the valid burden evidence. The process evaluates the evidence, receives a responsive safeguard, and changes A0 to A1.

```text
minority group size
≠ evidence validity

majority support for family A
≠ support for every version of A

correct family-level choice
≠ correct proposal terms
```

The five negative worlds all end with sincere 80 percent A support. They remain reference-defective because they adopt A0 rather than the evidence-responsive A1.

## Visibility custody

Evidence can exist in the record while being absent from the decision surface. A ranked brief, facilitator summary, retrieval system, or model context window can suppress counterevidence without deleting the source object.

A real process must therefore preserve:

```text
submitted evidence set
available evidence set
retrieved evidence set
visible decision evidence set
published evidence summary
```

Absence from one layer does not establish absence from the others.

## Epistemic quality and authority

PC-13 qualifies one reason-quality path. It does not make that path collectively binding or publicly sovereign.

```text
independent valid evidence
≠ consensus

minority correction
≠ collective agreement

reference-correct proposal
≠ public authorization
```

PC-06 continues to govern public standing and objective control. PC-08 governs negotiated agreement. PC-12 governs deliberative process and ballot-summary fidelity. PC-13 governs evidence dependency, integrity, visibility, and proposal-quality consequence.

## Real-case promotion boundary

A real epistemic-quality claim requires:

```text
evidence-item identity and content hash
source identity and root-source identity
derivation, citation, and replication graph
independence-cluster definition
speaker identity, role, affiliation, and source relation
model, checkpoint, corpus, retrieval, tool, and benchmark lineage
source validity, integrity, authentication, and audit state
inspection and replication records
presentation order and social-dependence state
submitted, available, retrieved, visible, and published evidence sets
ranking, suppression, summarization, and context-window logs
counterevidence identity, visibility, challenge, response, and uptake
proposal family, version, terms, constraint, and amendment lineage
private preference, ballot, and published disposition
reference outcome or later verification state
source-removal, de-duplication, visibility-restoration, or integrity counterfactual
implementation consequence and authority state
```

## Custody chain

Each world emits a SHA-256 hash-linked chain:

```text
baseline identity instrument reference and source registry
→ speaker claim source root derivation and visibility ledger
→ source independence integrity and inspection resolution
→ challenge response uptake and amendment ledger
→ private ballot publication and proposal-version state
→ dependency visibility or integrity counterfactual
→ epistemic-quality mechanism classification
→ interpretation seal
```

Mutating a root, parent, cluster, model lineage, validity state, visibility flag, challenge, uptake, proposal version, reference outcome, counterfactual, or classification breaks the chain.

## Publication boundary

The admissible laboratory statement is that one sincere 80 percent majority can rest on independent valid evidence, derivative laundering, shared-model monoculture, uninspected claim repetition, suppressed counterevidence, or fabricated evidence. A real epistemic-quality claim requires complete source dependency, model and corpus lineage, integrity, visibility, minority-correction, proposal-version, outcome, counterfactual, and authority custody.
