## Source admission and currency

The read-only source registry is `data/research/integrity-source-catalog.json`; it records each provider's access method, source/data license, relevant denominator, status, limits and whether an executable adapter exists. Reuse the existing official-source API and repository receipt/archive conventions; preserve:
- **Ceiling**, **obligation**, **payment/outlay**, **source-native Award Amount**, **valuation**, **loan commitment**, **signed contract**, and **delivered/accepted performance** as separate types.
- **Roster label**, **source-native recipient**, **UEI**, **filing CIK**, **EIN**, **corporation number**, and **fund or SPV** as separate identities until independent source evidence supports an exact typed join.
- Official source and retrieval dates, original bytes, JSON row index, source hash, pagination state, failed queries, nulls and rejected matches.
- No unverified personal profile enrichment, inferred motive or guilt, source-side privacy leakage or automatic public claim promotion.

USAspending is the first executable source because no API key is needed and exact public responses can be fetched and verified. GSA's SAM.gov Contract Awards API is now the authoritative contract-awards portal following the February 2026 FPDS.gov retirement. It requires a SAM account/API key; publicly revealed DoD awards also carry a 90-day disclosure delay. Do not infer missing contract actions from unpublished or delayed windows. Source: https://open.gsa.gov/api/contract-awards/ and https://sam.gov/fpds.

SEC EDGAR offers unauthenticated company-submissions/XBRL JSON with a declared-user-agent policy and a ten-request-per-second fair-access ceiling. OpenFEC supports committee/campaign disclosures with its own key and terms, including special restrictions on repurposing donor lists. SBA SBIR/STTR offers downloadable award history; its API was under maintenance in November 2026. IRS original 990s and ProPublica Nonprofit Explorer can support EIN-based institutional research. GovInfo's API requires an api.data.gov key. Each remains an independent source-specific task, not an alleged existing adapter.

## Community interoperability

**Adopt the minimum interchange, not a second estate.**

- **FollowTheMoney**: MIT-licensed entity model and library. The current acquisition emits 288 bounded source-native `Contract` stubs with contract IDs, source URLs and explicit interpretive notes, not a final joined ownership network. The stubs intentionally omit `amountUsd`: USAspending's generic `Award Amount` cannot be silently reclassified as an outlay, signed contract amount or guaranteed allocation. Before redistribution to a FtM consumer, validate against the installed official FtM schema and its actual loader.
- **Nomenklatura**: MIT-licensed candidate for scalable entity reconciliation and statement lineage. Its software may complement AXM, but it cannot replace Clifford's accepted identity criteria or source-specific legal-entity review.
- **OCDS**: Open Contracting Data Standard is a free, non-proprietary international publication format. A future adapter can map official validated awards into OCDS while leaving absent tender, signed contract and implementation/payment fields absent. The present candidate data are not represented as a complete OCDS release.
- **Aleph/OpenAleph**: Existing search/indexing/graph commodity software can be useful when a real reviewer requires hosted document search or large-scale discovery. No bulk server or new source-of-truth was launched; Clifford's existing static explorer remains the front door.
- **ICIJ**: An existing Clifford snapshot contains the Panama Papers relationship corpus. The wider Offshore Leaks data are ODbL with CC BY-SA contents and explicit non-accusatory identity boundaries; reuse requires attribution and share-alike review.
- **OpenSanctions**: Software projects are open source, but the compiled dataset generally is CC BY-NC and commercial reuse needs its own license. Do not silently ingest their commercial data into an Integrity.ai product.

## What constitutes a valuable review packet

For each candidate company: exact selected roster/source; normalized source-native UEI or CIK (when independent primary-source link exists); award IDs; agencies; award/transaction history; actual obligations, ceiling and paid amounts from fields that support each; grant or financing instrument; corporate filings; board/beneficiary rights; public procurement controls and performance acceptance; counterpart comparators; date window, source time, negative result and provenance. Where any join is missing, export **the next exact source/identifier to obtain**, not a guilty-looking graph edge.
