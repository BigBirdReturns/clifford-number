# Preference custody: negotiated package formation and collective bargaining

This candidate-only laboratory supports issue [#594](https://github.com/BigBirdReturns/clifford-number/issues/594). It closes a package-composition and collective-agreement boundary that remains after option generation: individual clause support does not determine support for the combined package, and package support does not itself establish a negotiated agreement.

The fixture is synthetic. It creates no graph effect, thesis evidence, real-world causal conclusion, bargaining-denial finding, imposed-package finding, preference-change finding, legitimacy verdict, manipulation claim, or inference of intent.

## Frozen population and component poll

The fixture contains 1,000 people in two equal affected groups. The package vocabulary is:

```text
X
Y
ALPHA_GUARD
BETA_GUARD
REVIEW
```

Independent component polling produces:

```text
X             600
Y             600
ALPHA_GUARD   400
BETA_GUARD    400
REVIEW       1000
```

A component-majority optimizer using a 50 percent inclusion threshold therefore selects:

```text
X + Y + REVIEW
```

Only 200 people accept that package. The two 400-person conditional cohorts each require a group-specific safeguard before accepting the other group’s preferred term.

The protected package is:

```text
X + Y + ALPHA_GUARD + BETA_GUARD + REVIEW
```

All 1,000 people accept it. The component marginals remain unchanged. The package-level result changes because the terms are conditional and non-separable.

## Five package worlds

### Marginal-majority bundle

The institution combines every component meeting the 50 percent poll threshold. The resulting package receives only 20 percent package support. The institution selects it without representative mandates, ratification, enforceable obligations, or collective agreement.

### Synthetic protected candidate

A synthetic candidate generator proposes the protected package. The package is acceptable to all fixture cohorts, but the model has no representative mandate, cannot make reciprocal concessions, cannot ratify the terms, and cannot bind implementation. It remains a candidate.

### Advisory protected package

Human participants propose the same protected package through advisory co-design. The institution approves it, but the process has no binding group mandates, ratification requirement, enforceable obligations, or remedy. High package support and human participation still do not create a collective agreement.

### Binding ratified protected package

Affected-group representatives hold attributed mandates. The negotiated term sheet preserves reciprocal concessions, a 75 percent ratification threshold in every affected group, enforceable obligations, a reopen clause, appeal, and remedy. Both groups ratify at 100 percent. The agreement binds implementation.

### Binding one-sided counteroffer and impasse

The counteroffer omits `BETA_GUARD`. Alpha ratifies at 100 percent and beta at 20 percent. The group threshold fails, reciprocal concessions are incomplete, no collective agreement forms, and implementation is blocked as a binding bargaining impasse.

## What the control proves

The same population and component poll produce:

```text
20% support for the marginal-majority bundle
100% support for a synthetic package candidate
100% support for an advisory package
100% support and one ratified collective agreement
60% support and one binding impasse
```

The relevant distinctions are package composition, conditional terms, representative authority, reciprocal concessions, group ratification, enforceability, and reopen or remedy rights.

The executable refusal rules are:

```text
marginal clause support ≠ package acceptance
package support ≠ collective agreement
synthetic package = candidate, not bargain
advisory co-design ≠ binding collective bargaining
representative mandate requires attributed membership
negotiated package requires reciprocity, ratification, enforcement, and reopen
failed ratification = binding impasse, not missing data
package terms require versioned custody
collective agreement requires group disposition
```

## Custody chain

Every package world emits a SHA-256 hash-linked chain:

```text
population and conditional package rules sealed
→ component poll recorded
→ versioned package proposal recorded
→ representative mandate state recorded
→ bargaining instrument sealed
→ package support and group disposition recorded
→ agreement or impasse resolved
→ implementation resolved
→ interpretation sealed
```

The component poll cannot overwrite the complete package terms. Package-level support cannot overwrite mandate and ratification state. A synthetic proposal cannot inherit representative authority. Advisory approval cannot overwrite the absence of collective agreement. A failed ratification remains a binding disposition rather than disappearing as nonresponse or model error.

## Real-case evidence floor

A real deployment requires:

```text
component poll and instrument
complete package terms and version
conditional acceptance or rejection rules
representative identity, membership, and mandate
proposal, counterproposal, and concession history
group ratification denominators, thresholds, and results
enforceable obligations and responsible actors
reopen, appeal, and remedy terms
agreement or impasse disposition
implementation or blocking receipt
```

A synthetic audience can generate package candidates, identify possible complementarities, or simulate responses to terms. It cannot negotiate on behalf of affected groups, make a concession they own, ratify an agreement, accept an enforceable obligation, or reopen the agreement after consequences appear.

## Promotion boundary

This control does not establish that Electric Twin, News UK, Dentsu, any vendor, any publisher, or any named institution imposed a package, denied collective bargaining, or caused an impasse. A real case needs observable terms, attributed representatives, mandate and ratification records, enforceable obligations, and an implementation consequence before package support can be narrated as a collective agreement.
