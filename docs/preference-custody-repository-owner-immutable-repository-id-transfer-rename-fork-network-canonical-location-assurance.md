# PC-56 repository owner, immutable repository identity, canonical location, fork, transfer, and rename custody

PC-56 is a synthetic Preference Custody control. It holds one complete-looking repository-owner and location surface constant while separating eight incompatible immutable-owner, repository-ID/name, canonical-location, repository-state, fork-network, transfer/rename-lineage, and succession states.

Only one world has complete custody. The control does not establish real repository ownership, source validity, security compromise, causal effect, graph fact, or public authority. It requires exact source and build identity, canonical JSON input custody, deterministic compilation, correction and rollback semantics, and an explicit no-outside-human boundary.
