# Clifford Number 2.0.0

Release line: 2.0.0, consolidation. Prepared on 12 October 2026.

This release makes the repository smaller and easier to check. It does not add research. Between June and September 2026 the project grew hundreds of workflows, hundreds of one-off validators and a long tail of programme documents. 2.0.0 keeps the part that protects the public result, removes the part that only supported past programmes, and says plainly what is left.

The compiler, the public application and the rules for what counts as a hop are the same as in 1.3.0. The constitution (BUILD-INSTRUCTIONS Section 1) is unchanged.

> **Correction (2026-10-22).** The public application was not the same as in 1.3.0 on the cut this note describes. The cut carried the two commits of the never-merged 1.4 branch (`da06da21`, `e24f5bd9`, authored on 14 September 2026 and cherry-picked onto the cut on 12 October 2026), which changed seventeen public files: a name search, a Depth slider and an Evidence-time scrubber on the Explore controls, the GPU field kept active at all four depth levels, dated activity pulses in place of the 1.3.0 link particles, a renamed aperture heading and rewritten homepage copy. The compiler and the hop rules were unchanged as stated. The change is recorded in [the 2.1.0 note](2.1.0.md#the-14-explorer-change-the-cut-already-carried). The same cut also failed `npm run release:check` in two places (stale manifests pinning `package.json`; a validator pinning the old heading), so the reproducibility claim under "Verify it yourself" did not hold until commit `58459f93f`, also recorded there.

## What changed

| | Before | After |
|---|---|---|
| GitHub workflows in `.github/workflows/` | 334 | 5 |
| Validator files named `tools/validate-*` | 386 | 171 (170 `.mjs`, 1 `.py` kept outside the gate) |
| npm scripts in `package.json` | 160 | 46 |

### Five workflows

| File | Runs | What it does |
|---|---|---|
| `ci.yml` | On every pull request and every push to `main` | Runs `npm run release:check`. |
| `deploy.yml` | On every push to `main` | Runs the same gate on the exact commit, then publishes `dist/` to GitHub Pages only if it passes. |
| `update-sweep.yml` | Only when a person starts it | Compiles the ledgers, runs the surface scout and prints its report. |
| `crawl-official.yml` | Only when a person starts it | Collects official-record observations and opens one pull request. |
| `crawl-industrial-exhaust.yml` | Only when a person starts it | Captures first-party company publications and opens one pull request. |

No workflow has a timer (`schedule`) or a `workflow_run` trigger. Before this release ten workflows ran on schedules, one of them every five minutes, and some of the crawl automation could merge into `main` without a person. All of that is off, and it stays off until someone adds it back by hand in a reviewed pull request.

Both crawls can push only a run-scoped `automation-crawl-*` branch and open a pull request. They cannot merge or approve it, start another workflow, or push to `main`. What they collect has no effect on the graph until a maintainer promotes it in a separate, reviewed change.

### Two checks that were prose are now mechanical

- **The receipt contract** (`tools/validate-receipt-contract.mjs`). Every receipt must have a resolvable source URL, an archive that resolves (a stored extract whose SHA-256 matches, or an Internet Archive snapshot), and a written statement of limits. To satisfy it, 51 receipts gained a limits statement and 11 gained a source URL copied from their own extract. No extract was edited, so no archive hash moved.
- **The constitution gates** (`tools/validate-constitution-gates.mjs`). Rule 1.6 (no aggregation on ethnicity, religion, ancestry, national origin or unit affiliation) and rule 1.9 (no paid placement, no undisclosed sponsor) now fail the build on the ledgers, the canonical files, the case ledgers and every data file on the publication allowlist. Both run inside `npm run check`.

### Three stale checks repaired

Three checks that lived outside `npm test` had gone out of date and were failing. Each was corrected to match the tree.

- A comprehension route still pointed at a surface that the August 2026 Dialog split retired. It now points at the dated successor and declares the exact set of surfaces it expects.
- One M-05 validator looked for text that had never existed in the test it pins.
- One status-sovereignty validator rejected a custody archive that was added on purpose.

### Programmes removed from the gate

The validators, tests, build tools and workflows of these programmes were deleted: the preference-custody laboratory, the counter-selector programme, Project Stable Ground, the status-sovereignty residual-denominator waves and RD-04 chains, the M-04D to M-04G wave chains, and the School.House registry validators. Fifty-four more files (validators and their tests) were deleted because they checked the exact bytes of workflows or validators that no longer exist. The sealed data they pinned was not edited.

## What is not claimed

- **No new findings.** No research was done for this release. It adds no claim, surface, participation row or hop to the ledgers. Registry counts are not restated here; see [`docs/identity-reconciliation.md`](../identity-reconciliation.md).
- **No outside review.** Every check, tier and judgment in this release was made by the project's own agents and maintainers. No independent party has reviewed the consolidation, the archive or the retrospective's tiers.
- **No claim that removed programmes were wrong.** Their validators were removed because they were process-only: they checked how a programme had been run, not what the public result says. Their documents and recovered research are kept.
- **No claim that everything old still passes.** Some validators outside the gate fail for reasons unrelated to this work: three compare the branch with `origin/main` or a later ledger state, one Python validator needs environment variables, and the browser tests need an installed Chromium. They are listed in the deletion record.
- **No scheduled growth.** Schedules are off. The project will not collect or add records on its own until someone turns a schedule back on by hand.

## Known open items

Most are in repository-only intake data for the Austin to Israel corridor cohort, and one is a count field in a published research map. They are not failures. Whether to keep, reword or remove that data is an owner decision that has not been made.
- The POOF ecology browser play-test (`test/poof-clifford-ecology-browser.test.js`) stays in the repository, but no workflow runs it. The POOF workflow's deterministic-rebuild diff and artifact upload are no longer automated either.
- Older documents may name npm scripts that were folded into `npm run check` or removed. The deletion record maps them.

## Verify it yourself

```bash
npm ci
npm test
npm run release:check
```

`release:check` compiles the ledgers, runs the validators including the receipt contract and the constitution gates, runs the tests, builds the Pages artifact and validates it against the publication allowlist. A hostile stranger running those three commands from a clean checkout should reproduce the result (BUILD-INSTRUCTIONS rule 1.8).

The publication allowlist (`data/project/publication-allowlist.json`) now reports version 2.0.0. It lists this note, the [retrospectives index](../retrospectives/README.md) and the [deletion record](../retrospectives/2026-10-12-consolidation-deletions.md) as published documents.
