# Clifford Number 1.3.0

> **Note (2026-10-22).** This note describes 1.3.0 as released on 14 September 2026 and is kept as written. The following sentences are no longer true of the current explorer; see [the 2.1.0 note](2.1.0.md) for what replaced them.
>
> - "323-node / 392-edge Research projection": `graph.json` has carried 346 nodes and 392 edges since commit `9e22d4e3` (the 2.0.0 evidence-lake identity merge added 23 person and organization nodes and no edges).
> - "animated sourced-activity particles" and "Motion is disabled under reduced-motion preference": the particles were replaced in the 1.4 change by dated activity pulses derived from the participation rows; since 2.1.0 a pulse exists only inside its row's time window, playback is off by default and never starts under reduced motion, and the field pauses when off-screen.
> - "Machine, surface, evidence, Route, and Surface modes still use the semantic SVG views" and "Route mode and semantic zoom return the stage to SVG": since the 1.4 change the GPU field stays active at all four Explore depth levels when WebGL is available; the SVG scenes are the fallback. Route and Roster remain SVG, and the Timeline added in 2.1.0 is SVG.
> - The heat projection described in the third paragraph no longer drives any visual channel: since 2.1.0 node size and halo are the documented surface count for the object.
> - "proving that activity particles are actually animated": that verification was of the 1.3.0 field and does not describe the current one.

Clifford Number 1.3 replaces the whole-corpus Map view with a GPU-rendered social field while preserving the existing compiler, evidence rules, bounded-surface semantics, and semantic SVG inspection views.

The new field renders the 323-node / 392-edge Research projection as a deterministic spherical shell. Curved arcs remain a one-for-one rendering of sourced Research edges. No visual edge creates a Clifford hop, no heat score creates actor-to-actor adjacency, and no animation asserts direction, coordination, influence, or causality.

Heat is a display projection over documented structure. It combines local documented degree, local clustering, bounded-surface recurrence, repeated co-surface reinforcement, and evidence weight. The same admitted graph always produces the same spherical seed coordinates and heat values.

The current GPU adapter uses Three.js 0.186.0 and 3d-force-graph 1.80.0. The adapter is deliberately downstream of `src/social-field.js`, so a later renderer can be replaced without modifying graph compilation, receipts, hop admission, or the social-field projection contract.

The whole-corpus field includes curved shell arcs, localized additive heat halos, GPU picking, orbit/zoom interaction, selection subordination, and animated sourced-activity particles. Motion is disabled under reduced-motion preference. WebGL failure falls back to the existing semantic SVG map.

Machine, surface, evidence, Route, and Surface modes still use the semantic SVG views where exact bounded objects, roles, dates, receipt IDs, dense-roster containment, and route steps are easier to inspect. The portable standalone explorer intentionally stays on that SVG path and remains below its existing 5 MB budget.

The public browser assets are vendored and exact rather than fetched from a CDN. Publication policy continues to scan the artifact and enforce file, byte, single-file, initial-shell, and standalone budgets.

Browser verification for this release exercised the live Visual Aperture shell in Chromium with software WebGL. Static-camera frame hashes changed across 750 ms intervals, proving that activity particles are actually animated. Route mode and semantic zoom return the stage to SVG, then restore the GPU field on return. WebGL-disabled Chromium falls back to SVG with no page error, and the mobile field remains responsive.

The Research source boundary is unchanged from 1.2: the legacy context base remains explicitly frozen at 2026-06-29, the deterministic projection clock remains 2026-09-12T03:00:00.000Z, and later canonical ledger maxima remain observations rather than a completeness claim. The canonical bounded-surface and verified-hop ledgers remain authoritative for Clifford Number semantics.
