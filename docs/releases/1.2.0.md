# Clifford Number 1.2.0

Clifford Number 1.2 reconciles the broad Research network with the deterministic release architecture introduced in 1.1. The release does not replace the bounded-surface Clifford Number with a looser contextual graph. It makes the Research projection reproducible, gives its legacy context an explicit provenance boundary, and overlays current canonical bounded-surface participation without manufacturing actor-to-actor relationships.

## Research projection

The Research network is now compiled from two separately declared inputs.

First, `data/research/research-context-base.json` preserves the accepted contextual graph through `2026-06-29`. That object is explicitly `context_only`, is not canonical for the Clifford Number, and remains byte-semantic input to the projection rather than using `graph.json` as its own source.

Second, the compiler projects current canonical actors, organizations, bounded surfaces, participation rows, and receipts into a topology-only surface overlay. The overlay adds actor or organization → bounded surface membership rows only. It adds zero actor-to-actor edges and therefore cannot create or shorten a Clifford route.

The resulting public Research graph contains 323 nodes, 392 edges, and 72 sources. Of those edges, 169 are canonical participant-to-surface topology rows. The underlying frozen context remains 194 nodes and 223 contextual edges.

## Dense and sensitive surfaces

The canonical density limit remains 19 actors. The 112-actor Dialog public-directory surface is represented as one counted surface container; its 113 participation rows are not expanded into visible pairwise-style spokes.

The legacy public-only guard also remains intact. One correspondence surface is withheld from the Research overlay because its source identifiers trip that guard. The release does not weaken the guard to increase graph coverage.

## Projection and source time

All public graph projections now use the admitted deterministic build clock `2026-09-12T03:00:00.000Z`. This aligns artifact identity; it does not claim uniform source freshness.
The Research boundary separately declares the frozen context base through `2026-06-29`, plus the receipt-bounded canonical overlay. The latest observed canonical surface date in this release is `2026-08-12`; the latest recorded receipt retrieval date is `2026-08-15`; and the latest receipt publication or event date observed by the overlay is `2026-07-08`. Those maxima describe records present in the admitted ledger. They do not prove that the corpus is complete through those dates.

`build/public-data-boundary.json` therefore distinguishes aligned projection clocks from mixed source boundaries. The Explorer shows both the Research projection build time and the frozen context-base cutoff instead of presenting one date as a universal freshness claim.

## Public case boundary

The compiled UK AI policy case remains bound to the frozen Research context base. Canonical topology-overlay rows are visible in the Research network but cannot silently inflate the case's claims, events, receipt counts, or case `as_of` boundary.

The bounded surface and hop projections remain authoritative for the Clifford Number. Version 1.2 retains 54 canonical bounded surfaces and 93 verified actor-hop edges under the existing participation, density, temporal-overlap, and receipt rules.

## Interaction and renderer

The semantic Atlas architecture from 1.1 remains in place: corpus → machine → surface → route → evidence. The SVG/DOM renderer remains appropriate at this public scale, with aggregation, collision-aware labels, viewport-local edges, route subordination, and dense-roster containment applied before any renderer migration.

The Research overlay expands contextual coverage without changing that rendering authority. Overlay surface glyphs are explicitly excluded from canonical organization backfill, preventing Research-only representation objects from contaminating the bounded-surface compiler.

## Reproduction

From a clean checkout with the supported Node runtime:

```bash
npm ci
npm run release:check
```
The release gate rebuilds the Research projection from its declared base and canonical ledgers, rechecks legacy-context fidelity, verifies that the overlay creates no pairwise actor edges, rebuilds all bounded projections and portable artifacts, binds the content-addressed artifact manifest, and validates the Pages payload.

## Evidence boundary

The release changes projection custody and contextual coverage, not evidentiary meaning. Context remains distinct from a hop; a hop remains distinct from causation; co-participation remains distinct from coordination; and an observed latest date remains distinct from proof of complete coverage. The exact roles, time windows, evidence classes, and source dates continue to live in their owning canonical rows and receipts.
