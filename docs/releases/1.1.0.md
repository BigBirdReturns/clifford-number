# Clifford Number 1.1.0

Clifford Number 1.1 makes the public instrument match the evidence architecture already present in the repository. It separates the causal homepage from the topology explorer, introduces a scale-dependent Atlas projection, and exposes the exact projection boundary behind each public view. The release changes representation and inspection mechanics; it does not promote an intake candidate, alter a canonical identity, manufacture a hop, weaken a dense-surface exclusion, or convert an open research frontier into a finding.

## Public surfaces

The root page is now a four-lane causal projection over the published research graph: model production, workflow admission, activation spend, and measurement feedback. It renders aggregate marks with named denominators, preserves the open missing-receipt aperture, and opens an aligned provenance view rather than implying a causal bridge where the corpus has none.

`explorer.html` is the full topology instrument. Its Atlas uses a semantic representation ladder:

1. **Corpus:** cases, domains, major aggregates, evidence composition, and structural corridors.
2. **Machine:** institutional containers, bounded surfaces, and counted inter-cluster bands.
3. **Surface:** the named bounded object, its participant grammar, window, eligibility, and evidence composition.
4. **Route:** actor → bounded surface → actor steps, alternate evidence-constrained routes, and blocked temporal steps.
5. **Evidence:** claims, receipt health, inference limits, and stable sortable inspection rows.

The renderer retains SVG and DOM because the admitted public graph remains small enough for accessible semantic objects: 194 contextual nodes and 223 contextual edges, alongside 182 admitted actors, 54 bounded surfaces, and 93 verified hop edges. The release reduces mounted geometry through aggregation, banding, locality, and semantic zoom before introducing a GPU renderer whose complexity would not improve the current evidence task.

## Projection boundaries

The public site now publishes `build/public-data-boundary.json` and renders its contents on both pages. That contract states which artifact governs each view:

- `graph.json`, generated `2026-06-29`, remains the broad contextual research projection and does not compute Clifford Numbers.
- `build/surface-graph.json`, `build/hop-graph.json`, and `build/receipt-graph.json`, generated from the admitted `2026-09-12T03:00:00.000Z` build clock, govern bounded participation, verified routes, and receipt metadata.

A projection timestamp identifies deterministic output. It is not an acquisition date, event date, verification date, or assertion that every underlying source was current at that instant. Those dates remain in their owning receipts.

## Interaction and legibility

The Atlas adds cursor-anchored zoom, semantic-level hysteresis, deterministic stable geography, collision-budgeted labels, selection and route subordination, viewport-local edge rendering, off-screen count stubs, dense-roster containment, evidence-constrained and as-of route projections, and an evidence overview that stays stable under hover and filtering. Each actor-to-actor abstraction resolves to a named bounded surface; context-only corridors remain visually and semantically distinct from Clifford hops.

The homepage and explorer preserve keyboard operation, reduced-motion behavior, semantic landmarks, responsive overflow, explicit inference boundaries, and direct receipt access. Portable outputs now include the causal homepage, a self-contained topology explorer with the full Visual Aperture workspace, a configurable endpoint standalone, and the existing Estate and Game-Trail standalones.

## Reproduction

From a clean checkout with Node 20:

```bash
npm ci
npm run release:check
```

The release gate rebuilds the canonical projections, public boundary, Atlas projection, Pages artifact, portable outputs, content-addressed artifact manifest, and browser-test surface. The protected deployment repeats the full gate, verifies the tested artifact identity before upload, confirms the live commit and manifest after deployment, and reruns the bounded browser suite against GitHub Pages.

## Research boundary

The release publishes the admitted evidence state without changing its meaning. Co-presence remains distinct from coordination. A contextual edge remains distinct from a Clifford hop. Absence from the corpus remains a statement about gathered documentation, not proof of real-world absence. NatSec100 canonical promotion, cross-case identity admission, external second-party review, staged POOF publication, crawler intake, and nonpublic recovery material remain governed by their owning records.
