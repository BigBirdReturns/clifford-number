# Federal Election Commission 1991–1992 original-source population

Source-adjacent, owner-local candidate. The initial source slice is the Federal Election Commission’s 1991–1992 committee master (https://www.fec.gov/files/bulk-downloads/1992/cm92.zip) and other-committee reported transactions (https://www.fec.gov/files/bulk-downloads/1992/oth92.zip). Both official URLs returned HTTP 200 and redirected to the official federal object store. Original compressed files and byte-bound observation receipts remain under the existing project session's ecology/expansion-canary/fec-1992/ custody, outside Git and the publication allowlist.

The real source reports 10,759 unique committee identifiers and 273,009 distinct FEC transaction record identifiers for the 1991–1992 election cycle. The 1992 committee master retains the FEC-issued ID (stable in FEC records), original committee name, organization category, candidate ID when supplied, and connected organization as a source label rather than an independently resolved corporate parent. The transaction file records the filer committee ID, other reported FEC committee/candidate ID when supplied, source type code, amendment indicator, original transaction date and exact reported amount. Rows without a matching second FEC ID remain in the source population with an explicitly unlinked counterpart. Original dates outside 1991–1992, including future-year source anomalies, remain qualified; no future obligation is inferred. Repeated/amended reports are separate FEC rows and amounts are not automatically summed, deduplicated into payments, or represented as disbursements settled.

Two source-native identifiers appearing in the same transaction constitute inspectable reported provenance, not legal ownership, adjudicated payment, control, intent or influence. Source transaction type 24K is classified using the FEC's published “Contribution made to nonaffiliated committee” code. Other types retain their original codes until independently qualified for directional interpretation. The adapter projects no individual donor names, addresses, employer or occupation. It excludes source name/address fields from the transaction derivative and omits the committee treasurer and address, while retaining the official ZIP privately for independent source inspection. The FEC warns that information on individual contributors cannot be used for commercial solicitation or sales; this project does not transfer it to another product or public surface.

Reference descriptions: https://www.fec.gov/campaign-finance-data/committee-master-file-description/ ; https://www.fec.gov/campaign-finance-data/any-transaction-one-committee-another-file-description/ ; https://www.fec.gov/campaign-finance-data/transaction-type-code-descriptions/ ; https://www.fec.gov/updates/sale-or-use-contributor-information/

The adapter is independent of the original three-lane acquisition process. Original captures and experimental output reside outside the canonical repository. If accepted, source-native ingestion requires a terminal acquisition owner and the existing exclusive lock, followed by full FTS/source-hash verification, native tests and bounded cross-ledger reconciliation. No public repository, graph, accepted payment, allegation or review state is modified here. Remaining population scope includes earlier and later FEC election cycles, underlying filed reports, amendment reconciliation, source-native candidate-to-committee links, institutional parent legal records and non-federal election authorities.
