# Methodology

The Clifford Number is the shortest evidenced path from a public node to the Clifford Policy Machine.

## Workflow

1. Add only public-role nodes: people, organizations, policy documents, government offices, forums, or infrastructure layers.
2. Connect nodes with typed edges. Avoid vague predicates such as “associated with.”
3. Attach source IDs for every edge.
4. Keep `listed`, `registered`, and `attended` separate.
5. Run `npm run check` before publishing.

## Search behavior

The web app searches node labels, IDs, aliases, types, descriptions, and tags. If a name is present and connected, the app returns the shortest path to the Clifford Policy Machine. If a name is absent, the app makes no adjacency claim.

## Boundary

No wrongdoing is alleged. The graph maps public institutional topology, not intent, ideology, character, or private life.

## Evidence upgrade paths (UK), learned in the gate 2.4 pass

- Post-2016 UK company-law reform removed named shareholder lists from
  confirmation statements: only pre-reform AR01s (and the itemized lists some
  companies still attach to CS01s) name investors. "Find the investor on a
  Companies House filing" is therefore not a general path for post-2016
  investments; where an itemized CS01 list exists (e.g. Electric Twin Ltd) it
  is government_record gold, and where it does not, GOV.UK declared-interest
  pages and FOI responses are the durable named-official path for
  public-appointment actors (this is how the Matt Clifford / Faculty edge was
  upgraded).
- Statutory-inquiry witness statements (covid19.public-inquiry.uk) are
  first-person sworn documents and upgrade employment and campaign-role
  claims to official in one receipt.
- parliament.uk and electoralcommission.org.uk currently sit behind
  Cloudflare and reject non-browser fetchers; DCMS committee evidence is the
  best known unretrieved source for the ASI / Vote Leave vendor link.
