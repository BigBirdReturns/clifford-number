# Official FEC 1993-1994 source-native continuation

The two source-declared public archives are https://www.fec.gov/files/bulk-downloads/1994/cm94.zip and https://www.fec.gov/files/bulk-downloads/1994/oth94.zip. The first contains 10,815 committee-master rows (ZIP SHA256 4126c9e24301a1b0b08ead4bcfb9a275e90e099cf0e475c902828435a166ddbf); the second contains 272,852 committee-to-committee reported transaction rows (ZIP SHA256 d8a77ab4cb1b4eb13d74b4556d6b4362c962893184e582c0381300728949ba05). Both official downloads redirect to the published federal object store, and both original member files have the declared field count (15 and 21). The first committee request encountered transient DNS failure; the subsequent ordinary official request succeeded, with both observations preserved. Original bodies and request receipts remain in the existing W03 ecology/expansion-canary/fec-1994 source custody, not Git or the public release.

The existing FEC interpreter has been extended with an explicit election-cycle parameter and retains 1992 behavior as its default. Cycle 1994 selects the two exact 1994 official archives and classifies original dates against 1993-1994, preserving malformed, out-of-cycle and future-year source dates without interpreting them as scheduled commitments. The same original FEC committee and transaction identifiers, source-line SHA256, source amounts, amendment indicators, registered labels and source-native counterparty namespaces are retained, but no name-only legal ownership, bank settlement or public actor relationship is inferred. The 1992 and 1994 sources are separate record populations and source identifiers; repeated committee IDs may identify continuous FEC registrations, not duplicate economic transactions.

The FEC contributor-rights notice https://www.fec.gov/updates/sale-or-use-contributor-information/ remains binding. Derived records exclude individual donor names, addresses, employers, occupations, treasurers and location data. All amounts are filed amounts, not verified payments. Original S3 bodies remain privately held. A 1994 row count establishes coverage of these two particular official ZIP members, not all campaign finance, independent factual review or complete election-cycle filings.

Accepted original-source tests in test/test_ecology_fec_1994.py validate both complete captures, retained source identifiers, cycle-aware dates, source hashes, original redirects, malformed receipt rejection, personal-data omissions, source-native money states and unsupported future-cycle refusal. Production adoption must follow independent real source replay, existing acquisition-lock ownership and DB/FTS checks; earlier-cycle figures remain separately identified. Publication and canonical graph promotion are outside this source adapter.
