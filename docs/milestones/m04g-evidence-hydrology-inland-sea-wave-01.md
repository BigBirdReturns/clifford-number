## Hydrology

```text
ocean discovery
→ high recall, archives, metadata, graphs, research, news, and code

freshwater authority
→ law, courts, audits, awards, filings, standards, and enforcement

tributary voice
→ represented people, workers, operators, plaintiffs, witnesses, and communities

aquifer depth
→ FOIA, discovery, technical logs, appendices, transition files, and restricted records

estuary
→ independent classes converge on the same exact deployment, instrument, date, threshold, consequence, right, or remedy

inland sea
→ normalized, provenance-preserving candidates awaiting human adjudication
```

## Continuous operation

The permanent workflow:

- validates source counts, identifiers, catchments, promotion ceilings, and non-automation boundaries;
- builds a deterministic searchable report;
- executes the full repository release gate;
- runs a daily freshwater pulse and weekly ocean tide on public allowlisted endpoints;
- restores cached source state and records changes by headers, hashes, and bounded summaries;
- uploads refresh artifacts rather than committing uncontrolled network output;
- refuses direct-voice bulk polling and authenticated or restricted acquisition.

## Cross-estate routing

The sea feeds:

- M-04B organism packets and theater bridges;
- M-04F vertical joins and stratigraphy;
- F20–F46 Flock-like sensing and action lanes;
- Pattern-to-Proof source freezes, nulls, falsifiers, and reconciliations.
