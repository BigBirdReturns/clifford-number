# M-05 Sprint 08 — A1 support lifecycle

Sprint 08 closes the post-approval counterfeit gap. Sprint 06 created clean-room reproduction intake and Sprint 07 separated independence, evidence, challenge, and registry adjudication. This sprint makes any later A1 support claim challengeable, suspendable, revocable, expiring, supersedable, and restorable only through renewed external review.

## Permanent package

- six lifecycle roles with ministerial and substantive authority separated;
- eight append-preserving states and explicit transition law;
- ten public challenge categories;
- twelve automatic support-loss triggers;
- public and protected challenge issue forms;
- challenge, support-incident, and lifecycle-transaction schemas;
- a structural CLI that never mutates the registry or determines external truth;
- an empty, append-preserving support ledger;
- twenty-four frozen adversarial scenarios and twenty-four executable negative cases;
- deterministic JSON and HTML reports with an exact-byte release manifest.

## Boundary

This sprint creates refusal and transition rules. It does not establish that an A1 entry exists, that a challenge is true, that a support-loss trigger occurred, that independent adjudication happened, or that any registry state changed. It authorizes no real-person pilot.
