# School.House IRS candidate latest-filing XML v6 custody

## Decision

This product preserves a fresh deterministic custody layer over the successful, privacy-minimized latest-filing XML acquisition produced by workflow run `31109883159` and artifact `8971196288`.

It is intentionally versioned **v6**. It does not claim byte identity with the previously proposed v5 permanent package. The v5 carrier asserted a 34,492-byte bundle with SHA-256 `8d708c542e632eb528cf89a79f6b1482e2495ec49d1bbd33c08c352b80963c4e`, but the checked-in Git blob was measured by hosted run `31128178906` as only 20,083 bytes with SHA-256 `7e255a2b5ebfde99d7da80f681a256c3b505d4809a2eef55f613f146ee678cc2`. That mismatch is a typed transport defect with no product, source, identity, relationship, absence, publication, adoption, or graph authority.

V6 reuses the eight acquisition-derived files byte-for-byte, preserves the acquisition `SHA256SUMS`, and rebuilds only the authored custody, documentation, validator, adversarial test, and builder layer.
