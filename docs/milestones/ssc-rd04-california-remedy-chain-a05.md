# SSC RD-04 A05 · California CalFresh remedy chain

A05 executes the exact selected-state handoff from A04 without reopening state selection and without requiring any outside person. California remains selected only because A04’s predeclared rule retained it inside the five-state highest-coverage tie.

## Result

California publishes all seven procedural surfaces needed to describe a nominal consequence-and-remedy chain: adverse-action notice, hearing request, aid pending, withdrawal or pre-hearing resolution, hearing and decision, rehearing or judicial review, and compliance or restoration. The FY 2025-26 State Hearings report also supplies CalFresh-specific aggregate throughput at several stages.

The records do **not** join those stages into one claimant cohort. CalFresh filings, withdrawals, scheduled hearings, held hearings, decisions, and rehearing requests are separate program totals. Decision dispositions and rehearing determinations are reported only across all programs. Published compliance and restoration rules do not establish actual implementation, timing, completeness, or downstream material outcome.

```text
procedural stages:                         7 / 7

case-level linked stages:                   0 / 7
complete case chains:                       0
CalFresh disposition distributions:         0
CalFresh rehearing determination mixes:     0
restoration timing denominators:             0
external reviews:                           0
graph effect:                               none
```

## Anti-join law

A withdrawal is not presumed favorable. A hearing count is not joined to a filed-appeal count. A decision count is not joined to a hearing count. The all-program disposition and rehearing tables are not assigned to CalFresh. Procedure is not execution, and aggregate throughput is not individual effective counterpower.
