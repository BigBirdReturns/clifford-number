# Preference Custody PC-27: interference, network spillover, and exposure-mapping custody

PC-27 is a synthetic control for the gap between a public `interference_adjusted` label and the actual assignment, network, channel, exposure, interference, estimation, correction, and authority record needed to support that label.

The control preserves one public publication surface while changing the hidden data-generating and exposure-governance system. It does not audit a named network, treatment, policy, institution, or population. It creates no graph effect, thesis evidence, real-world causal finding, score-use authorization, public-authority verdict, manipulation finding, discrimination finding, coercion finding, breach finding, misconduct finding, or inference of intent.

The public label and headline estimates therefore do not distinguish the eight underlying systems.

## The eight worlds

### Complete predeclared exposure map

The positive world preserves ten predeclared clusters, concealed randomization, a complete pre-treatment node and edge census, a complete institutional-channel map, one stable treatment version and dose, zero true control exposure, an exposure map that exactly reconciles classified and true exposure, a valid direct and spillover estimand, current lineage, independent audit, and operational correction.

```text
true exposed controls            0
false-negative exposures         0
missing edges                    0
cross-cluster edges              0
treatment versions               1
rewired edges                    0
ambient saturation exposure      0
complete assurance            true
```

This is the only complete interference-assurance path.

### Direct peer spillover

Thirty nominal controls receive a spillover dose through treated peers inside the declared clusters. The public exposure ledger still reports zero exposed controls.

```text
true exposed controls           30
classified exposed controls      0
false-negative exposures        30
independent direct effect      0.08
independent spillover effect   0.12
```

Cluster randomization preserves assignment provenance. It does not preserve an unexposed control group.

### Shared institutional-channel contamination

Forty nominal controls share operators, facilities, policies, or workflows with treated units. The person-level network is complete, but the institutional channel map is not.

```text
true exposed controls           40
institutional exposures         40
shared-channel exposures        40
cross-cluster channels           5
channel map complete         false
```

A person-level network cannot stand in for the institution, workflow, media, market, or infrastructure through which treatment can propagate.

### Cross-cluster diffusion

Fifty observed edges cross the declared cluster boundary and expose twenty-five nominal controls.

```text
cross-cluster edges             50
cross-cluster exposures         25
partial interference        unsupported
```

The cluster boundary is an analytical declaration. It is not an observed membrane.

### Incomplete network census

All one hundred nodes are present, but four hundred of six hundred true edges are absent from the census. Forty control exposures remain hidden.

```text
observed nodes                 100
true nodes                     100
observed edges                 200
true edges                     600
missing edges                  400
network coverage              1/3
hidden control exposures       40
```

Complete node coverage is not complete edge coverage, channel coverage, or exposure coverage.

### Treatment versions and doses collapsed

Thirty treated units receive one of three versions or doses, but the publication treats the intervention as one stable treatment.

```text
treatment versions               3
multiple-version units          30
versions distinguished       false
doses distinguished          false
```

A single treatment label does not establish one treatment, one dose, or one response function.

### Post-assignment network rewiring

The treatment changes network topology. The system then uses a post-treatment network snapshot to construct the exposure map.

```text
network census time             30
assignment time                 10
rewired edges                  100
true exposed controls           20
exposure map predeclared     false
network stable               false
```

A current network can be a treatment descendant. It cannot be silently substituted for the pre-treatment exposure structure.

### Market and institutional saturation

Media, market, policy, and institutional channels alter the environment for all one hundred units. Every nominal control is indirectly exposed.

```text
true exposed controls           50
ambient saturation exposure    100
truly unexposed controls         0
unit-level untreated counterfactual unavailable
```

A unit-level comparison does not survive when the intervention changes the common environment.

## Exposure reconciliation

For every world, the validator enforces:

```text
classified exposed controls
- false-positive exposures
+ false-negative exposures
=
true exposed controls
```

It also requires true exposed controls to reconcile to the indirectly exposed control denominator. The fixture cannot hide exposure by changing one ledger without changing the others.

## Network and channel separation

PC-27 stores the person-level network and the institutional channel map separately.

The network ledger carries node and edge counts, missing edges, cross-cluster edges, rewired edges, collection time, version, coverage, and audit state.

The channel ledger carries operators, facilities, policies, workflows, media, markets, shared-channel exposure, cross-cluster channels, version, and mapping state.

A complete graph of people can remain incomplete as an exposure model when treatment travels through institutions, shared services, common policy, media, markets, or infrastructure.

## Treatment stability

The control distinguishes:

```text
treatment identity
approved version
executed version
version count
dose state
spillover dose
whether versions are distinguished
whether doses are distinguished
```

Stable assignment does not imply stable treatment. A valid causal interpretation requires the relevant treatment versions and doses to be named in the estimand and exposure map.

## Partial interference

Partial interference is supported only when the declared clusters correspond to the observed exposure boundary. PC-27 requires:

```text
no cross-cluster network edges
no cross-cluster institutional channels
no unresolved edge undercoverage
stable pre-treatment network
no general-equilibrium pathway
```

A clustering variable alone cannot supply those facts.

## Estimation boundary

The positive path requires a valid exposure map before an exposure-adjusted estimator can identify a spillover estimand. Network adjustment, cluster-robust uncertainty, or a zero spillover coefficient cannot repair an incorrect exposure model.

The analysis ledger preserves:

```text
direct estimand
spillover estimand
estimator identity
reported effects
independent effects
exposure adjustment
cluster adjustment
network adjustment
misclassification correction
sensitivity analysis
falsification tests
unsupported decisions
```

## Lineage and correction

The lineage contract binds the approved and executed treatment, network, channel map, and exposure map. Current validation requires exact version agreement, a current revalidation state, and a succession receipt.

The governance ledger then preserves audit, monitoring, map refresh, rollback, correction, appeal, certificate withdrawal, publication authority, and the explicit absence of binding public authority.

## Hash-linked custody

Each world emits ten linked events:

```text
public interference publication
assignment and population
treatment and network topology
institutional and ambient channels
true and classified exposure
interference assumptions and equilibrium
estimands and estimation
lineage and governance
mechanism classification
interpretation seal
```

Every event contains the previous event hash. The build validator rejects altered payloads, broken source order, duplicate event identifiers, invalid signatures, and custody-head drift.

## Refusal rules

```text
cluster randomization is not absence of interference
nominal control assignment is not unexposed control
complete node coverage is not complete edge, channel, or exposure coverage
person-level network map is not complete institutional or market exposure map
predeclared exposure mapping is not correct mapping when decisive channels are omitted
zero observed cross-cluster edges is not partial interference when shared channels cross clusters
stable assignment is not stable post-assignment network
one treatment label is not one stable treatment version or dose
network-adjusted estimator is not a valid exposure model
cluster-robust uncertainty is not correction for spillover or exposure misclassification
zero reported spillover is not zero true spillover
current network snapshot is not pre-treatment network
saturation or general equilibrium is not a unit-level untreated counterfactual
public interference-adjusted status is not complete, current, exposure-aware, correctable, and publicly authorized evidence
interference failure is not proof of coercion, manipulation, discrimination, breach, misconduct, or intent
```

## Promotion boundary

A real interference-adjusted claim requires complete custody of assignment, clusters, networks, channels, treatment versions, exposure categories, classification error, partial-interference assumptions, network change, saturation, equilibrium, estimands, estimation, uncertainty, falsification, lineage, monitoring, correction, durability, and authority.

PC-27 remains a graph-inert synthetic control. Its function is to prevent a public interference label, cluster randomization, complete node count, or robust standard error from laundering an incomplete exposure model into a causal finding.
