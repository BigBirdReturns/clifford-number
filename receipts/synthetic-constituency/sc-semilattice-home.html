Accuracy

Tested against real people, question by question.

Each user model is built from real human data. Accuracy is measured by comparing its predictions with how real people answered. Every model’s test results are shown in the product.

Simulation engine

Anacreon

Anacreon is built from interviews, reviews and open-ended survey responses. It simulates hundreds of individual respondents, each modelled on one real person, so you can segment and re-cut the results. The first public user models built with it are coming soon. With Semilattice Custom, we build one from your own research.
