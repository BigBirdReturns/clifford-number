## Purpose

The wave converts the status-output mismatch into a testable acquisition surface without laundering personal experience into a macro finding.

The program asks whether a candidate repeatedly produces valid movement, exception recovery, custody, transfer, and clean handoff beyond what conventional status metadata predicts. It does not infer hidden genius from precarity, rejection, breadth, AI use, outsider identity, or grievance.
