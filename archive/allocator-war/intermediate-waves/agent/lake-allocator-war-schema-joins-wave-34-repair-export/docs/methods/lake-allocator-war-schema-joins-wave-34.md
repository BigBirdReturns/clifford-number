# Allocator-war source schemas and lawful joins Wave 34

Wave 34 consumes only the permanent Wave 33 parse objects. It performs no network request and does not reinterpret frozen response text. Each of the nineteen parse rows receives one source-specific adapter that may expose only a structurally observed field, array, metric, HTTP state, or access boundary.

The adapter layer distinguishes a structural handle from an institutional join key. A field such as `document_number`, an award identifier, a docket number, or an agency code may be a candidate reconciliation key. It does not establish that two records concern the same contested action, person, entity, instrument version, consequence, or correction.

Seven join contracts correspond to the seven Wave 31 route classes. Each contract preserves five candidate key classes and the complete missing institutional requirements required before a join may be authorized. The protected-personnel contract is confined to privacy-safe aggregate or otherwise authorized lawful access. HTTP 403 responses and credentialed systems remain access outcomes. The Grants.gov response token is excluded before projection.

A Wave 34 product is valid only when every Wave 33 parse is adapted exactly once, every mapped field is structurally observed, all thirty-one requirements remain unsatisfied, authorized joins and joined rows remain zero, the complete repository gate passes, and the restored committed epoch reproduces the same product.
