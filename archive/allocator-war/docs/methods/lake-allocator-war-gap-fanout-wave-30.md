# Allocator-war missing-row observability and closure fan-out Wave 30

## Object

Wave 30 consumes the twelve bounded Wave 29 execution results and treats each explicit `unavailable_rows` entry as an independent acquisition obligation. It does not summarize several missing rows into one broad task and it does not permit an omitted row to disappear inside a narrative status.

The source denominator contains five estate queues, twelve source tasks, and thirty-eight explicit missing rows. Every missing row receives one stable task reference, one route class, one route owner, one execution state, one receipt contract, and one stop rule.

## Route constitution

The fan-out uses seven reusable acquisition lanes.

1. `protected-personnel-records` covers person-level decision and affected-party rows that require privacy-safe aggregate data or otherwise lawful record access.
2. `internal-authority-and-inventory` covers agency submissions, implementing offices, delegations, versions, exceptions, overrides, recusals, dissent, and decision custody.
3. `public-award-and-contract-denominators` covers base award, recipient, contract, contractor, agency, amount, programme, and timing universes.
4. `published-enforcement-and-action-registers` covers certifications, reviews, referrals, investigations, sanctions, settlements, declinations, withdrawals, replacement rules, and no-action rows where an issuing system enumerates them.
5. `correction-dockets-and-outcomes` covers grievances, appeals, protests, dockets, settlements, compliance, remedy, access, cost, unsuccessful paths, and durability.
6. `affected-comparator-and-distributional-joins` covers affected, unaffected, comparator, burden, no-effect, recurrence, substitution, reversal, and distributional consequence rows.
7. `financial-recovery-and-continuity` covers continuity, substitution, exit, clawback, repayment, recovery, loss, performance, and public-private value allocation.

A route class is an acquisition mechanism rather than a finding. Sharing a route class does not establish identity, relationship, coordination, common purpose, prevalence, or a common causal process.

## Amortization rule

One deterministic build emits all thirty-eight tasks. A later source change replays only the affected route class. Manual per-task dispatch is prohibited. No route may close its own source gap in the same wave that creates the task, and no route result may become evidence without the independent review and promotion controls already required by the estate.

The protected-personnel route is access-bounded rather than publicly executable. Public absence is not encoded as secrecy, motive, uniformity, or proof that no decisions occurred. The other six routes remain publicly executable, but their base systems, published actions, dockets, and aggregates retain their own coverage limits.

## Completion law

A complete action denominator requires action, declination, negative, inactive, and no-action rows. A formal coverage category is not a person-level denominator. A public award or contract universe is not an action roster. A published enforcement announcement is not a complete register. A remand, dismissal, or settlement is not practical correction without implementation, timing, access, cost, and durability evidence. An announced payment or replacement programme is not realized public recovery without execution and performance records.

Wave 30 creates no complete denominator, evidence adjudication, estate adoption, finding, graph effect, or publication authority.
