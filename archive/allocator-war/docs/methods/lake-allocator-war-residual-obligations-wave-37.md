# Method: allocator-war residual institutional obligation adjudication Wave 37

Wave 37 is a deterministic comparison layer between the permanent Wave 36 component-custody results and the thirty-one completion tests inherited from Wave 35. It performs no network acquisition and creates no new institutional fact. Its unit of analysis is one Wave 36 task-result row, not one source, actor, organization, award, docket, policy instrument, or repeated identifier.

For every task result, the builder preserves the exact source task, queue, join, and requirement references; the source join and requirement hashes; the target institutional row; the completion test; the unresolved completion gap; the refused substitution; the access class; the captured source and component references; and the component hashes. The source row is also assigned a deterministic digest so later reconstruction can detect silent changes in the inherited object.

Each task enters one of two custody states. A public or lawful-case task with at least one Wave 36 institutional component becomes `component_observed_completion_test_open`. A protected-personnel task becomes `protected_access_obligation_preserved` and must retain zero public component rows and zero Wave 36 network requests. Neither state passes the completion test.

The seven route classes determine the residual obligation class, next lawful access route, and operational priority band. Priority band 1 covers internal authority, complete public-money denominators, and complete action and no-action registers. Priority band 2 covers practical correction, affected and comparator populations, realized payment, recovery, and continuity. Priority band 3 preserves protected lawful-access-only personnel chains. Priority orders acquisition work only. It is not evidence strength, truth, harm, intent, prevalence, coordination, or importance.

A record holder may need to respond before a requested source can be obtained. That dependency is distinct from human review authority. Missing reviewers, outside volunteers, or recipient acknowledgements do not block reversible internal classification, deterministic queue construction, validation, or the next bounded public acquisition attempt.

Wave 37 rejects the following substitutions: official component count for institutional completeness; official provenance for a passed completion test; a partial register for an action and no-action denominator; a repeated identifier for a lawful join; docket presence for practical correction; an announced amount for realized payment; and public workforce aggregates for protected personnel decisions.

The permanent output is one route summary for each of the seven route classes and one residual obligation for each of the thirty-one Wave 36 task results. The complete release gate must reproduce the exact ledger, projection, report, graph digests, route denominator, priority denominator, and zero-promotion boundary from the committed epoch.
