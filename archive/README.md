# archive/

**Read-only. Never published.** `archive/` and `retrospective/` are held rules in `data/project/publication-allowlist.json` (validated by `tools/lib/publication-allowlist.mjs`), so they can never enter the Pages artifact. Nothing here is edited after the fact: each folder says where it came from and how to check it. The tiers and one-line findings are the retrospective's judgment (`retrospective/2026-10-12/trails/tiered-trails.json`), not an outside review; trail rows are cited by their 0-based position in that file's top-level array.

## How each folder is organised

- `SOURCE.md`: exact origin: branch(es) and full commit ids, merge-base with main, pull request and issue numbers, the retrospective path (`preservation.json` entry, `branch-only-analysis.json`, `lake-branch-heads.tsv`, issue and comment exports), trail row, and how files were selected.
- `EXPORT-MANIFEST.tsv` (lake programmes only): git blob SHA-1 and size of every file in the folder moved from `retrospective/2026-10-12/branches/`.
- `MANIFEST.tsv`: every file with its git blob SHA-1 (`git hash-object <file>` reproduces it), size, and where it is stored. A file whose bytes are already archived elsewhere is a pointer, not a second copy.
- Selection rule for branch content: files added or modified on the branch since its merge-base with main, in research directories only (`data/ docs/ cases/ receipts/ contributions/ reports/ briefs/ comprehension/ estates/ gametrails/ gametrail-handoffs/ issue-handoffs/ legacy/ schemas/`), whose blob is absent from main. `tools/`, `test/`, `build/` and `.github/` are never copied.
- `INDEX.json`: the same index in machine-readable form, including every branch (tip, merge-base, aliases, PRs, trail rows, counts).

Where several branches have byte-identical research content they share one folder, and each alias branch has a `SOURCE.md`-only folder of its own naming the shared one.

- Issues referenced by #29-#52 but outside that range (for example #594, the performative-constituencies successor case) remain in the retrospective exports.
