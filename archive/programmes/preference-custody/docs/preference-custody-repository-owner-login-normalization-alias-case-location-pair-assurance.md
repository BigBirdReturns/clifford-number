# PC-60 owner-login normalization and location-pair assurance

PC-60 is a synthetic Preference Custody control. It holds one complete-looking repository-owner login, profile, API, and location-pair publication surface constant across eight incompatible custody worlds. The worlds separate complete assurance from Unicode and casefold substitution, incomplete case history, alias and rename gaps, recycled or reserved names, profile URL drift, API endpoint/version drift, cross-owner or nonconcurrent pairing, and stale inherited lineage.

The compiler projects only approved fields, binds exact world-state snapshots, computes the bounded burden ledger, and emits a five-event SHA-256 custody chain. The validator rejects non-canonical JSON containers, sparse or named arrays, accessors, non-enumerable properties, symbols, custom prototypes, proxies, exotic objects, repeated identities, cycles, unsupported values, negative zero, non-finite numbers, aggregate-preserving burden redistribution, partial state mutation, stale builds, and authority inflation.

The control creates no real ownership, transfer, impersonation, account-state, security-compromise, graph, publication, adoption, causal, intent, or public-authority finding.
