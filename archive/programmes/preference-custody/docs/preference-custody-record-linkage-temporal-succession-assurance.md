# Preference Custody PC-39: record linkage, namespace, temporal identity, and succession custody

## Status

PC-39 is an eight-world synthetic control. Every world preserves the same public `linkage_verified` surface while changing cross-source linkage, namespace separation, alias resolution, temporal validity, identifier retirement and recycling, predecessor-successor custody, retroactive relinking, append-only versioning, correction, lineage, and authority.

```text
source records                 100
linked records                 100
published linkage coverage     100%
published unmatched records        0
published ambiguous links          0
namespace status               current
temporal continuity            complete
succession continuity          complete
approved use                   longitudinal_exposure_estimation
```

Only one world has complete assurance. The seven incompatible failure worlds preserve namespace collision, alias fragmentation, temporal contradiction, identifier recycling, successor conflation, silently bridged succession gaps, and retroactive relinking without append-preserving history.

The control is not a real identity map, longitudinal entity history, exposure trajectory, graph fact, causal conclusion, named-actor allegation, or public-authority verdict. A real linkage claim requires source, namespace, alias, entity, temporal interval, identifier lifecycle, predecessor, successor, ambiguity, adjudication, version, correction, durability, and authority custody.
