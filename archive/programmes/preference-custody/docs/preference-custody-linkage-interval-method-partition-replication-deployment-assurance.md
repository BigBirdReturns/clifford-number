# Preference linkage-interval method, partition, replication, and deployment assurance

PC-48 is an eight-world synthetic control for a complete-looking linkage-interval method publication surface. Every world publishes the same method, deterministic-replay, out-of-sample, deployment-applicability, coverage, miss-count, interval-width, and approved-use badges while preserving a different implementation, runtime, partition, exchangeability, replication, deployment, or lineage state.

The qualified control preserves exactly one complete method-assurance world. The other seven worlds retain explicit bounded defect burdens without becoming real-world error, prevalence, welfare, causal, graph, allegation, misconduct, or authority findings.

The validator freezes the public surface, interpretation contract, complete per-world state and burden vector, descriptions, mechanisms, classifications, exact ISO capture date, object schemas, projected fields, source hash, custody chain, and deterministic reconstruction. Aggregate-preserving burden redistribution, partial state mutation, unrecognized fields, stale source/build pairing, and custody tampering are rejected.

PC-48 resolves only the method-code, configuration, seed, partition, exchangeability, replication, deployment-applicability, and current-lineage frontier. Runtime-artifact numerical determinism and deployment monitoring, shift-trigger, rollback, withdrawal, and release-succession governance remain independently open.
