# Preference linkage event, estimand, scope, and interpretation assurance

PC-47 is an eight-world synthetic control for a complete-looking linkage-interval publication surface. Every world publishes the same event, estimand, target-population, empirical-coverage, miss-count, interval-width, and approved-use badges while preserving a different event, censoring, estimand, population, unit, horizon, support, tail, or interpretation state.

The qualified control preserves exactly one complete semantic-assurance world. The other seven worlds retain explicit bounded defect burdens without becoming real-world error, prevalence, welfare, causal, graph, allegation, or authority findings.

The validator freezes the public surface, interpretation contract, complete per-world state and burden vector, world descriptions, mechanisms, classifications, ISO capture date, object schemas, projected fields, source hash, custody chain, and deterministic reconstruction. Aggregate-preserving burden redistribution, partial state mutation, unrecognized fields, mutable claim-bearing prose, impossible dates, stale source/build pairing, and custody tampering are rejected.

PC-47 resolves only the event/estimand/population/unit/horizon/support/tail/interpretation frontier. Method code, configuration, seed, data partition, exchangeability, replication, and deployment-applicability governance remain independently open.
