
## Refusal boundary

The control enforces, among other separations:

```text
100% node coverage ≠ complete network coverage
stable node count ≠ stable identity
declared analytic boundary ≠ operational system boundary
binary adjacency ≠ direction, sign, weight, layer, hyperedge, or context fidelity
three snapshots ≠ temporally feasible paths
current topology ≠ pre-treatment topology
high stability coefficient ≠ stable edge identity or path validity
reconstructed edge ≠ observed or independently validated edge
model fit ≠ path validity
post-assignment topology ≠ exogenous exposure map
zero published missing edges ≠ zero true missing edges
topology_verified ≠ complete, current, dynamic, correctable, publicly authorized evidence
```

A topology failure does not prove coercion, manipulation, discrimination, breach, misconduct, coordination, common purpose, or intent. A real topology or exposure-path claim still requires complete identity, boundary, edge, layer, temporal, treatment, reconstruction, hidden-edge, path, dynamic-exposure, succession, correction, durability, and authority custody.
