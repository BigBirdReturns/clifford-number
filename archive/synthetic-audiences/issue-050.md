## What changed

This PR makes the synthetic-population research fan-out durable inside the repository rather than leaving it only in GitHub issue prose.

- adds a staged program manifest with the Electric Twin seed case, 18 independently bounded child cases, and 20 second-order frontier candidates
- links the manifest to program issue #30, seed case #29, child issues #31 through #48, and frontier issue #49
- gives every case its own public-interest question, neutral selection unit and universe, source families, allowed predicates, forbidden inferences, and measurable acceptance condition
- adds one machine-readable discovery seed for every bounded case while keeping those seeds outside the canonical public-interest fan-out source plane
- adds a staged selection declaration with comparison symmetry, exclusions, privacy controls, pending second-party review, and a sunset condition
- adds staged coverage accounting that distinguishes durable research architecture from observed evidence and reports zero completed case receipt packets, zero independently reviewed cases, zero promoted canonical claims, and zero graph effects
- preserves `graph_effect: none`, machine-proposed status, and publication blocking throughout
- adds a validator that checks the program, selection, coverage, and seed registries together
- adds regression tests for graph-effect leakage, duplicate issue assignments, frontier publication leakage, case-count drift, selection leakage, coverage overstatement, and seed leakage
- adds a path-filtered GitHub Actions workflow and program documentation

## Why

The Electric Twin investigation exposed multiple distinct mechanisms: state-to-market personnel movement, institutional succession, acquisition-scale capability transfer, scientific validation, analyst category formation, media and political deployment, data rights, benchmark design, infrastructure dependence, capital rights, and labour substitution. Treating them as one expanding company biography would create target-first selection bias and allow evidence from one layer to launder another.

The program therefore requires every seam to remain independently coherent if Electric Twin or any named political actor is removed from the corpus. Cross-case recurrence can be calculated only after each case establishes its own denominator, receipts, evidence states, dates, controls, and refusal conditions.

## Public boundary

This PR does not modify canonical actors, organizations, claims, surfaces, participation rows, receipts, scores, the hop graph, `data/research/public-interest-discovery-seeds.jsonl`, the public application, or publication-ready narration. It stages research instructions under `contributions/inbox/research-batches/` only.

Co-presence remains non-coordination, broad institutions remain non-hops, capability remains distinct from deployment, investment remains distinct from operational control, role overlap remains distinct from scientific compromise, and source failure remains distinct from absence.

The selection declaration is publicly reproducible but explicitly excluded from public evidentiary progress. The coverage file counts contracts and gaps rather than findings. The frontier queue is explicitly inadmissible until each candidate has a neutral universe, at least one addressable positive anchor, a plausible negative or ordinary control, a privacy and legal-status boundary, a reproducible source path, and an acceptance test that can return positive, negative, inconclusive, or inadmissible.
