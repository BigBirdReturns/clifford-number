## How it was computed

- Every pull request head came from the all-refs bundle on branch `archive/retrospective-2026-10-12` (`retrospective/2026-10-12/git-bundle/`). The four parts were concatenated, the SHA-256 checked (`55fca0402cd4264629bd746621cf19971cbf3d60eebbebf40ba45d544d5c3d42`), `git bundle verify` passed, and `refs/pull/*` was fetched from it: 2,069 heads (all equal to the head recorded in `github/pulls-full.jsonl`) and 4 merge refs.
- Merged pull requests: the head commit was tested with `git merge-base --is-ancestor <head> origin/main` (`main` at `d8392cfb19b8fd870bc65e5a3dcf9a8ae4bcfb07`).
- Closed and open unmerged pull requests: files added or modified between the merge-base with main and the head (`git diff --raw --no-renames --diff-filter=AM`), minus `.github/`, `build/`, `dist/`, `node_modules/` and carrier scaffolding (any file under a hidden top-level work directory such as `.pc40/` or `.tmp/`, under `tmp/` or `transport/`, and base64 chunk files, which include every `TRIGGER`/`EXECUTE` file). Each remaining file's blob at the head was compared with: (a) the same path on the working branch, or the same blob at another path there (`landed`); (b) any blob under `archive/` or `retrospective/` (`archived`); otherwise it is `bundle-only`.
- Issues: state and author from `github/issues-full.jsonl`; closed-today from `prune/closed.tsv`; the pointer path from `prune/issues-to-close.tsv` where present, otherwise a rule by programme. Every pointer path was checked against the tree at this commit (a glob must match at least one file). Every issue body and every comment was also confirmed present in `github/issue-bodies.jsonl` and `github/issue-comments-full.jsonl` (599 of 599 bodies; comment counts match for all 599).

## What "bundle-only" means

A file is bundle-only when its exact bytes (git blob hash) are not in the working branch's tree and not under `archive/` or `retrospective/`. It can still be recovered, from the all-refs git bundle on branch `archive/retrospective-2026-10-12` (`git fetch <bundle> 'refs/pull/*:refs/bundlepull/*'`, then `git show refs/bundlepull/<N>/head:<path>`). It is not on main and not in `archive/`. A pull request is `bundle-only` when none of its files match, and `partly-archived` when some do and some are bundle-only.
