## Where the retrospective overreaches

The archive summary said that no vendor named its model, cloud or subprocessors. Preserved issue #46 contradicts that assertion. Comment 5016549280 records Yabble naming OpenAI and AWS and CulturePulse naming AWS, Hotjar and Stripe. Comment 5016630066 records Synthetic Users' named model/cloud providers, regions and subprocessor disclosures. These remain vendor-authored disclosures, rather than observed runtime traces or completed validation reruns. The archive index is corrected; the original issue and comments remain unchanged.

The cost review's recommendation that only merged material counts as product fails against the D: implementation: two unmerged commits contain working visualization improvements. Code-directory exclusion is an archival selection rule, not an assessment of code quality. The remaining bundle-only versions need recovery when they supply a real missing capability; making every old version browsable would create another preservation task rather than improve the application.

The trail map's categorical novelty judgment is unsupported by a novelty investigation. Its outside-review recommendation can improve a consequential argument, but it does not establish a universal prerequisite for analysis, source inspection or operation. The appropriate evidentiary burden depends on the proposition being asserted. Descriptive arithmetic, an existence claim, a comparative effect and a universal causal explanation require different evidence.

Similarly, a zero count under a demanding conjunction of conditions is evidence about that conjunction. It does not automatically mean that the underlying acquisition found nothing. The allocator collection's 150 official-source captures and the observed pieces of effective correction retain value even where no complete institutional row or seven-component case was assembled.

## Code and process disposition

The cost analysis records 536 SNAP-programme PRs, with 79 percent opened after the last new state sources in that series; a 255-PR controller loop; and a preference-custody family with 119 library/validator chains and extensive synthetic fixtures. These categories overlap and PR counts are not labor-hour measurements. They nevertheless identify repeated processing after evidence or functionality ceased advancing.

Retain the temporal/density/identity components, receipt and source importers with demonstrated use, case compilation, the query path, useful rendering and the publication/correction components. Retire repeated carrier orchestration, synthetic-floor expansion, recurring gap-closure rounds that change no conclusion, and universal adoption/reviewer machinery. The 2.0 consolidation already removes much of that code and workflow mass; this session does not claim credit for its earlier deletions.

The local application suite previously invoked seven records-request lifecycle subtests through the shareholder-evidence test. Those preparation, dispatch, delivery and response tests now have their own explicit entry point, `node test/electric-twin-register-request.test.js`. The shareholder-evidence assertions remain in the normal suite. No test implementation or historical source was discarded.

A real Windows portability defect surfaced in bundle hashing: GNU `sha256sum` can prefix its filename-bearing output with an escape marker, which the parser treated as part of the digest. Hashing the bundle through standard input avoids that filename encoding. The contract test now accepts the equivalent form, and the runtime bundle-digest assertion proceeds successfully.
